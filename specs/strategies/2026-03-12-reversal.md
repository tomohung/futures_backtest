# 轉折回歸策略（Reversal Strategy）

## 1. 背景與動機

現有策略（ORBLong、EstHL）皆以**突破**為核心邏輯，表現最佳時段為單邊趨勢明顯的日子。

本策略針對**開盤夾在機構成本之間**的情境：市場對昨日與前日的成本尚未形成共識，價格在兩層成本之間震盪。此時突破策略容易被雙向洗盤，而**均值回歸**策略較有優勢。

### 核心假設
- 開盤價夾在 BigCost1（昨日）與 BigCost2（前日）之間 → 市場方向未定，容易產生均值回歸行情
- 30 分 K 20MA 提供大方向（日內趨勢偏多或偏空）
- 1 分 K BB 極值（超買/超賣）+ 放量 + CCD 確認 → 短期反彈/反壓進場點
- 1 分 K 5MA 確認動能已開始轉向

---

## 2. 假設與方向

**核心假設：** 當開盤夾在兩層機構成本之間，市場往往在這個區間震盪；BB 極值加上放量是短期過度延伸的信號，配合 CCD 確認方向後反彈/反壓。

**與 ORBLong 的差異：**
- ORBLong：等突破 OR 上緣，追勢
- 本策略：等 1m 超買/超賣後反轉，逆短勢順大勢

## 4. 策略設計

### 4.1 開盤條件（進場前提，當天有效）

```
min(BigCost1, BigCost2) < open_price < max(BigCost1, BigCost2)
```

- `BigCost1`：昨日日盤放量 VWAP（高成交量 bar 的成交均價）
- `BigCost2`：前日日盤放量 VWAP
- 開盤價 = 當日 08:45 的第一根 1m K 的 open

若不滿足此條件，當天不進場。

### 4.2 方向判斷（30 分 K 20MA）

| 信號 | 條件 |
|------|------|
| 偏多 | Close30 > MA30_20 |
| 偏空 | Close30 < MA30_20 |

- `Close30`：最近完成的 30m K 收盤價（shift 1，無 lookahead）
- `MA30_20`：30m 收盤的 20 期 SMA（shift 1，無 lookahead）

### 4.3 進場條件（全部滿足才進場）

| 指標 | 做多（偏多日） | 做空（偏空日） |
|------|--------------|--------------|
| **BB** 1m K, period=20, std=2 | close ≤ BB_Lower | close ≥ BB_Upper |
| **Volume** 1m K | volume > vol_ratio × VolMA20 | volume > vol_ratio × VolMA20 |
| **CCD** 5m K（日內累積） | CCD > 0（淨買壓） | CCD < 0（淨賣壓） |
| **1m 5MA** | close > MA5_1m | close < MA5_1m |

所有條件同時為真時，市價進場（trade_on_close=True，使用當根 close 估算）。

### 4.4 出場

| 出場類型 | 計算方式 |
|----------|---------|
| 止損（SL） | 進場價 ∓ EmaHL × sl_ema_fraction |
| 止盈（TP） | 進場價 ± EmaHL × tp_ema_fraction |
| 強制出場 | 13:40（收盤前 5 分鐘） |

每天最多進場一次（_entered flag）。

### 4.5 進場時窗

- 開始：09:00（等 BB 有足夠 warmup，且 30m 第一根完成）
- 結束：13:00（預留出場時間）

## 5. 指標計算細節

### Bollinger Bands（1 分 K）
```python
close_roll = df["close"].rolling(bb_period)  # bb_period=20
bb_middle = close_roll.mean()
bb_std = close_roll.std()
df["BB_Middle"] = bb_middle.shift(1)
df["BB_Upper"] = (bb_middle + bb_std_mult * bb_std).shift(1)  # bb_std_mult=2.0
df["BB_Lower"] = (bb_middle - bb_std_mult * bb_std).shift(1)
```

### Volume 20MA（1 分 K）
```python
df["VolMA20"] = df["volume"].rolling(20).mean().shift(1)
```

### 1m 5MA
```python
df["MA5_1m"] = df["close"].rolling(5).mean().shift(1)
```

### CCD_5m（每日重置，映射回 1 分 K）
```python
from src.indicators.volume import cumulative_candle_delta

ccd_list = []
for date, day_df in df_day.groupby(df_day.index.date):
    s5 = day_df.resample("5min").agg({"open": "first", "close": "last", "volume": "sum"})
    s5 = s5.dropna(subset=["open", "close", "volume"])
    ccd = cumulative_candle_delta(s5["open"], s5["close"], s5["volume"])
    ccd_shifted = ccd.shift(1)  # 使用上一根完成的 5m bar 值
    ccd_1m = ccd_shifted.reindex(day_df.index, method="ffill")
    ccd_list.append(ccd_1m)

df_day["CCD_5m"] = pd.concat(ccd_list)
```

## 9. 備選方案

若主策略信號太少（每年 < 30 筆）：
- 放寬 BigCost 夾擊條件：允許開盤在 BC1/BC2 ± 50 點緩衝區內
- 放寬 BB 條件：改用 %B ≤ 0.2（接近下軌）而非嚴格觸及下軌

若勝率過低（< 40%）：
- 加入 DailyADX 濾網（ADX < 20 表示橫盤，均值回歸效果更好）
- 限定 OR% 範圍（OR 不能太大，避免趨勢日）
