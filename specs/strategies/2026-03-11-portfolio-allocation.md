**日期：2026-03-11**

## 背景

經過多個 Phase 的策略開發，目前有三個成熟策略：

| 策略 | 類別 | 進場窗口 | 出場機制 |
|------|------|----------|----------|
| EstHL | `ORBWithEstHLExitStrategy` | 08:58–09:15 | EmaHL SL + SatZone 兩段式 + Dow Trail |
| DirA | `EstHLEntryORBLongExitStrategy` | 08:58–09:15 | 固定 % SL + OR×TP + Trailing |
| ORBLong | `ORBLongStrategy` | 09:00–11:00 | 固定 % SL + OR×TP + Trailing |

---

## 各策略最佳參數

### EstHL（`ORBWithEstHLExitStrategy`）
```python
sl_ema_fraction = 0.25   # SL = 0.25 × EmaHL
entry_end_min   = 555    # 進場截止 09:15（555 = 9×60+15）
bigcost_days    = 2      # BigCost 回看天數
long_only       = True
```
資料需求：`load_data_for_orb_est_hl()`

### DirA（`EstHLEntryORBLongExitStrategy`）
```python
sl_pct           = 0.004   # 固定停損 0.4%
tp_or_multiplier = 3.0     # TP = entry + 3.0 × max(OR寬度, 20)
or_min_width     = 20.0    # OR 寬度下限保護
bigcost_days     = 2
entry_end_minute = 15      # 進場截止 09:15
long_only        = True
```
資料需求：`load_data_for_orb_est_hl()`

### ORBLong（`ORBLongStrategy`）
```python
sl_pct           = 0.004   # 固定停損 0.4%
tp_or_multiplier = 1.5     # TP = entry + 1.5 × OR寬度
trend_ma_days    = 10      # TrendMA 回看天數
```
資料需求：`load_data_with_night_ma(trend_ma_days=10)`

## 結論與建議

### ✅ 最佳組合：EstHL + ORBLong（各½口）

**理由：**
1. **Sharpe 最高（3.12）**，比三策略均分（2.93）高 0.19
2. **真正的策略分散**：日相關係數僅 0.171，進場時段不重疊（09:15 vs 09:30+）
3. **無虧損年**（2021–2026），最差年 +18 點
4. **合計點數接近三策略**（4,346 vs 4,304），多一個策略卻沒帶來對應收益

**為什麼不加 DirA：**
- DirA 與 EstHL 日相關 0.746，加入後只是稀釋 EstHL 的資金
- 三策略均分的 Sharpe 反而低於 EstHL + ORBLong
- 在資金固定的前提下，加入高度相關的第三策略是負效益

### 次選：三策略均分（若追求絕對穩定）
- 2021 最差年 +301（比 EstHL+ORBLong 的 +18 更穩）
- 但 Sharpe 更低、2022–2025 年度報酬也更低
- 適合對 2021 類低波動年份特別保守的配置偏好
