## 0. 這份文件涵蓋什麼

三條同源指標，全部建立在同一個核心動作上：**把「現價相對當日開盤的位移」除以該標的的典型日振幅，再 tanh 壓縮**。

| 指標 | 標的宇宙 | 量什麼 | 起跑時間 |
|------|----------|--------|----------|
| **現貨版 ext_long** | W10（最大 10 檔權值股，現貨分K） | 開盤後**上行**延伸力（窄權值） | 現貨開盤 09:00 |
| **期貨版 ext_long** | W10 個股期 / 或 NYF(0050期) 單檔 | 同上，但用個股期報價 | 期貨開盤 08:45（早 15 分） |
| **現貨版 ext_short** | W100 寬權值 ＋ 全市場漲跌家數 | 開盤後**下行**壓力（寬廣度） | 現貨開盤 09:00 |

> **本文重點：原專案（chart-ui）是盤後一次跑整天 panel；目標專案吃即時數據。**
> 數學完全相同，差別只在資料管線。第 1 節先講即時計算模型（三層），第 2–4 節給每條指標的數據／來源／公式，第 5 節給校準常數，第 6 節給移植檢查清單。

原始實作參照：`src/chart_ui/services/extension.py`（本文行號均指此檔）。

## 1. 即時計算模型（最重要：盤後 batch → 即時 streaming 的對應）

原專案做法（盤後）：把當天**整天**的分K拉成 `pivot_table(index=minute, columns=stock_id, values=close)`，`ffill()` 後一次向量化算完所有分鐘（`extension.py:65-66`）。

即時環境**沒有整天 panel**，要改成「**日特徵預算 + 即時狀態維護 + 每 snapshot 歸約**」三層。三層各自的責任：

### 第 1 層：日特徵（盤前一次算好，當天不變）

這些全部來自**日線歷史**，且都是 **causal（只用到昨日及更早）**，所以**開盤前就能全部備妥**：

| 量 | 定義 | 何時可知 |
|----|------|----------|
| `prev_i` | 個股 `i` 的**昨日收盤**（漲跌家數的基準） | 盤前 |
| `range_i` | 個股 `i` 日振幅 `high−low` 的 **causal EMA20**（`shift(1)` 後 ewm span=20；不含當日） | 盤前 |
| `w_i` | 個股 `i` 的權重 = **20 日均成交值**（`shift(1)` 後 rolling20，min 10 期） | 盤前 |
| 宇宙 W10 / W100 | 依 `w_i` 由大到小排序取前 10 / 前 100（`extension.py:81-82`） | 盤前 |
| `open_i` | 個股 `i` **當日開盤價**（錨點） | **開盤當下**（現貨 09:00 / 期貨 08:45） |

> `range_i` 公式：`extension.py:44-45`；`w_i`(=`trail_val`)：`:46-47`；`prev`：`:48`。
> `open_i` 是唯一**開盤才知道**的日特徵——在它確定前，該檔的延伸無法計算（見各指標的「起跑時間」）。

### 第 2 層：即時狀態（逐筆／逐 snapshot 維護）

對宇宙內每檔 `i`，維護兩個值：

- `last_i` = 最近一筆成交價（**這就是 ffill**：即時情境下「最後成交價沿用到下一筆」天然等於 `ffill`）。
- `traded_i` = 今日是否已有成交（布林）。**開盤瞬間多數個股尚未成交**，此旗標是即時版的核心：未成交者在不同指標中處理不同（見下）。

### 第 3 層：每個 snapshot 的歸約（套公式）

每到一個輸出時點（建議**對齊 1 分鐘**，與原校準一致；更密也可，數學不受影響），用第 1+2 層算出當下的 ext_long / ext_short。公式見第 2–4 節。

**即時版的兩個關鍵 NaN 規則**（與 batch 版逐行對應，`extension.py:75-76, 94`）：

1. **thrust（ext_long 的 W10、ext_short 的 W100）**：某檔**尚未成交** → 用該檔 `open_i` 代入 → `m_i = tanh(0) = 0`，即「中性、不投票」，避免污染。對應 `P_thr`（`:76`）。
2. **漲跌家數（ext_short 的 `s_B`）**：只統計**真的成交過**的檔（`traded_i = True`），未成交者**不計入** up/dn/active。對應 `P_real` 仍為 NaN 的處理（`:75, 94`）。

## 2. 現貨版 ext_long（窄權值上行延伸）

### 2.1 需要哪些數據

| 數據 | 頻率 | 即時來源 |
|------|------|----------|
| W10 內每檔現貨**現價** `last_i` | 即時逐筆 / snapshot | 行情 feed（券商 API / 交易所 snapshot） |
| 每檔當日**開盤價** `open_i` | 每日一個（09:00 定） | 同上 |
| 每檔 `range_i`、`w_i`、宇宙 W10 | 每日一個（盤前） | 日線歷史 |

### 2.2 數據來源（本專案 ↔ 可攜）

- 本專案：現價／開盤＝`stock_min`（分K close）；`range_i`/`w_i`/`prev`＝`stock_day`（市場限 TWSE，`extension.py:37`）。
- 可攜：現價換成任何即時 feed 的最後成交價；日特徵換成任何日線來源。**介面就是 §1 第 1 層那張表 + 即時 `last_i`**。

### 2.3 公式組成

逐 snapshot `t`、對 W10 內每檔 `i`：

```
m_i(t)      = tanh( (last_i(t) − open_i) / range_i )          # 未成交 → last_i:=open_i → m_i=0
ext_long(t) = Σ_{i∈W10} w_i · m_i(t)  /  Σ_{i∈W10} w_i        # value-weighted（只納 w_i>0）
```

對應 `extension.py:79`（`m`）、`:84-91`（`wthrust`）、`:91`（`ext_long = wthrust(w10)`）。

- **為何 W10**：H111/H114 OOS 複驗——窄宇宙 OOS 零衰退、W50 解釋力 OOS 掉 0.12；上行延伸集中在最大幾檔權值股即足夠（2330 一檔權重壓倒性），加寬只引入雜訊。
- **強門檻 `STRONG_LONG = 0.16`**（`extension.py:28`，全窗 @09:30 top~20%）。

## 3. 期貨版 ext_long（盤前領先版）

與現貨版**同一指標的鏡像**，只換兩處：**資料源**（現貨→個股期報價）與**錨點**（現貨 09:00 open → 個股期 **08:45 open**）。因個股期 08:45 開、現貨 09:00 開，這條線**早 15 分鐘**起跑，可在現貨開盤前估出落點，全日亦可與現貨版 overlay。

### 3.1 需要哪些數據

| 數據 | 頻率 | 即時來源 |
|------|------|----------|
| W10 內每檔**個股期現價** `F_i(t)` | 即時 | 期貨行情 feed |
| 每檔個股期**當日 08:45 開盤價** `F_i(open)` | 每日一個（08:45 定） | 同上 |
| 每檔 `range_i`、`w_i`、宇宙 W10 | 每日一個（盤前） | 日線歷史（沿用現貨日線即可，見 3.3） |

### 3.2 公式組成

```
m_i(t)      = tanh( (F_i(t) − F_i(open)) / range_i )
ext_long_fut(t) = Σ_{i∈W10} w_i · m_i(t) / Σ_{i∈W10} w_i
```

與 §2.3 逐行相同，只是 `last_i→F_i(t)`、`open_i→F_i(08:45 open)`。

### 3.3 三個實作要點

1. **為何錨 08:45 open 而非期貨昨收**：要與現貨版 apples-to-apples 對照，就必須**同樣錨 open、把隔夜跳空歸零**。錨昨收會把跳空灌進來，量綱不同，對照即破功。（跳空本身是另一個獨立問題，不混入。）
2. **分母 `range_i`**：預設沿用**現貨日線**的 causal EMA20 日振幅（個股「典型日內幅度」性格，與用期貨振幅差異甚微）；要完全自包含可改用**個股期自身日振幅** EMA20，二擇一、同次計算內須一致。
3. **契約選擇**：本指標用 scale-invariant 的 `tanh((F−open)/range)`，**標準契約與小型契約算出的 `m_i` 相同**，契約大小與數學無關。真正準則是**報價新鮮度／流動性**：per-symbol 取量大、bid/ask 緊、時間戳最新者；**預設標準契約優先、近月優先**，近月接近結算量縮時 roll 次月。

### 3.4 單檔 MVP（NYF / 0050 期）

若拿不到完整 W10 個股期，可退化成**單一指數標的**直接套公式：

```
ext_long_fut(t) = tanh( (NYF(t) − NYF(08:45 open)) / range_0050 )
```

- 這是**「指數延伸」**（單一標的位移），不是「W10 breadth 延伸」，兩者同質、不同標的。
- `range_0050`：NYF 自身日振幅 causal EMA20（需匯入 ≥20 日滾動視窗）；或 0050 現貨日振幅 EMA20。
- 用於「盤前領先 + 與現貨指數方向對照」這個用途仍成立，且更貼近指數本身落點。

> **空方為何只有現貨版**：個股期只有權值股有足夠流動性，**廣尾漲跌家數覆蓋不足**，做不出可信的期貨空方版。故期貨版**只有多方**。

## 4. 現貨版 ext_short（寬廣度下行壓力）

**注意**：ext_short **不是** ext_long 的相反數。它是另一組件——**W100 寬權值的下行 thrust ＋ 全市場漲跌家數**，兩者各自 z-score 後相加。符號約定為「**下行壓力越大、值越正**」。

### 4.1 需要哪些數據

| 數據 | 頻率 | 即時來源 |
|------|------|----------|
| W100 內每檔現貨**現價** `last_i` | 即時 | 行情 feed |
| 每檔當日**開盤價** `open_i` | 每日一個 | 同上 |
| **全市場（全 TWSE）**每檔**現價**與**昨收** `prev_i`（算漲跌家數） | 即時（現價）／盤前（昨收） | 全市場 snapshot **或**交易所直接公布的漲跌家數 |
| 每檔 `range_i`、`w_i`、宇宙 W100 | 每日一個（盤前） | 日線歷史 |
| 固定 z 尺度常數 μ/σ（見 §5） | 常數 | 校準產物 |

### 4.2 公式組成（三步）

**Step 1 — 寬權值下行 thrust `s_thr`**（W100 value-weighted，取負號）：

```
m_i(t)  = tanh( (last_i(t) − open_i) / range_i )          # 未成交→open→m_i=0（同 §1 規則 1）
s_thr(t) = − [ Σ_{i∈W100} w_i · m_i(t) / Σ_{i∈W100} w_i ]
```

對應 `extension.py:92`（`s_thr = -wthrust(w100)`）。

**Step 2 — 全市場漲跌家數 `s_B`**（淨家數比，取負號）：

```
up(t)     = #{ i : traded_i 且 last_i(t) > prev_i }       # 只算真的成交過的（同 §1 規則 2）
dn(t)     = #{ i : traded_i 且 last_i(t) < prev_i }
active(t) = #{ i : traded_i }
s_B(t)    = − ( up(t) − dn(t) ) / active(t)
```

對應 `extension.py:94-98`。**注意比較基準是「昨收 `prev`」，不是 open**（這是傳統漲跌家數定義）。家數宇宙是**全 TWSE**（不只 W100）。

**Step 3 — 兩者各自標準化後相加**（固定 z 尺度，等權）：

```
ext_short(t) = (s_thr(t) − THR_MU) / THR_SD  +  (s_B(t) − B_MU) / B_SD
```

對應 `extension.py:99`。μ/σ 為**全窗 @09:30 校準的固定常數**（§5），**不是** rolling z。

- **為何 W100 / 全市場家數**：H112 OOS——連續壓力表 corr 穩 +0.31~0.36（但**離散關卡地圖已否證**，故此指標只當「連續壓力讀數」用，勿拿去預測「會不會觸及某關卡」）。空方靠的是**廣度**，所以 thrust 用 W100、家數用全市場，與多方的 W10 窄宇宙相反。
- **強門檻 `STRONG_SHORT = 1.33`**（`extension.py:29`，z-sum 全窗 top~20%）。

### 4.3 即時版的家數來源選擇

全市場逐檔 snapshot 在即時環境成本高。兩個可選：
1. **自算**：訂全 TWSE 現價，逐檔比 `prev_i`（最忠於原實作）。
2. **用交易所公布的漲跌家數**：多數行情商有「上漲/下跌/平盤家數」即時欄位，可直接代入 `up/dn/active`。**但須留意定義差異**（是否含試撮、是否以昨收為基準、是否含全部市場）——若定義不同，§5 的 `B_MU/B_SD` 需重校。

## 5. 校準常數與門檻（直接搬會有風險，務必重校）

原專案固定 z 尺度（`extension.py:24-26`，全窗 250 日 2025-06~2026-06 @09:30 校準）：

| 常數 | 值 | 用途 |
|------|-----|------|
| `THR_MU` | `0.01590` | `s_thr` 標準化中心 |
| `THR_SD` | `0.15487` | `s_thr` 標準化尺度 |
| `B_MU` | `-0.04558` | `s_B` 標準化中心 |
| `B_SD` | `0.39559` | `s_B` 標準化尺度 |
| `STRONG_LONG` | `0.16` | ext_long 強門檻參考線 |
| `STRONG_SHORT` | `1.33` | ext_short(z-sum) 強門檻參考線 |

> ⚠️ **這些常數綁定「原專案的盤後 1 分K last 價」語意**。目標專案的即時 feed 若價格語意不同（last trade vs 參考價、是否含試撮、snapshot 頻率不同、家數定義不同），**μ/σ 與門檻都需用目標 feed 自身樣本 @09:30 重新校準**。校準方法：累積一段樣本，取每日 @09:30（或你選定的對齊時點）的 `s_thr`、`s_B` 分佈算 μ/σ，門檻取分佈 top~20% 分位。

## 6. 移植檢查清單（每條指標備齊即可重建）

### 共用（三條都要）
- [ ] 日特徵管線（§1 第 1 層）：`prev_i` / `range_i`(causal EMA20) / `w_i`(20日均成交值) / 宇宙排序，全部 `shift(1)` causal。
- [ ] 即時狀態管線（§1 第 2 層）：每檔 `last_i` + `traded_i`，含 ffill＝沿用最後成交。
- [ ] 兩條 NaN 規則：thrust 未成交→open(m=0)；家數未成交→不投票。

### 現貨版 ext_long
- [ ] W10 名單（20 日均成交值前 10，causal）。
- [ ] W10 各檔即時現價 + 當日 09:00 開盤價。
- [ ] tanh + W10 value-weighted（§2.3，~10 行）。

### 期貨版 ext_long
- [ ] W10 各檔**個股期**即時報價 + **08:45 開盤價**（或單檔 NYF MVP）。
- [ ] 契約選擇規則（標準/近月優先、看流動性）。
- [ ] `range_i` 來源決定（現貨日線 or 個股期日振幅，二擇一）。

### 現貨版 ext_short
- [ ] W100 各檔即時現價 + 開盤價（算 `s_thr`）。
- [ ] 全 TWSE 漲跌家數來源（自算 or 交易所欄位）＋ 各檔昨收 `prev_i`（算 `s_B`）。
- [ ] 固定 z 常數 μ/σ（§5，**需用目標 feed 重校**）。
- [ ] `ext_short = z(s_thr) + z(s_B)`。

備齊對應區塊即可複製該指標，與原專案其餘程式無耦合。
