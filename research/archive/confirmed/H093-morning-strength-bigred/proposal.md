# Proposal: 早盤強勢 → 大長紅

## ID
H093

## Derived From
Origin（原創 — 來自盤面觀察）

## Trading Intuition
盤面觀察：當天開盤後就一路往上漲，到 10:30 仍然收在相對高的位置（沒有回吐），
直覺上這種「早盤強勢且守住高點」的型態，當天收盤容易形成大長紅。
想驗證：早盤強勢守高位，是否真的能預測當日收大長紅，且機率是否顯著高於無條件 base rate。

## Hypothesis
當「10:30 的收盤價位於早盤區間（08:45~10:30 的 high/low）高位（位置 ≥ 0.75）」時，
當日（日盤 08:45 開盤 → 13:45 收盤）形成「大長紅」的機率，顯著高於所有交易日的無條件 base rate。

「大長紅」需同時滿足兩個條件（漲幅 + 收高位）：
1. **漲幅**：日盤實體漲幅 `(close_1345 - open_0845) / open_0845` ≥ 門檻（門檻於 Phase 1 由分佈決定，初擬 +0.6% ~ +1.0%）
2. **收高位**：13:45 收盤位於當日全幅高低區間（08:45~13:45 的 day_high/day_low）上緣，位置 ≥ 0.85

價格序列一律使用連續合約 `adj_close`（Panama 調整，避免換倉跳空汙染）。

## Expected Distribution
- 觸發樣本（早盤守高位）應有數百筆以上（多年資料）。
- 觸發日的大長紅機率 vs 無條件 base rate：若觀察成立，應看到明顯 lift（如 base rate ~15% → 觸發後 > 30%）。
- 同時也看反例：觸發後反而收黑 / 大幅回吐的比例（衡量「假突破」風險）。

## Invalidation Condition
以下任一成立則假設不成立或無交易價值：
1. 觸發後大長紅機率 ≤ 無條件 base rate（無 lift，10:30 高位不具預測力）。
2. 觸發樣本數過少（< 100 筆），無法得出穩健結論。
3. 觸發後「收黑或大幅回吐」的尾端風險過高（如 > 30%），代表早盤強勢無法守住，型態不可靠。

## Notes
- 「早盤區間高位位置」定義：`pos = (close_1030 - low_morning) / (high_morning - low_morning)`，pos ∈ [0,1]，越接近 1 越高。
- 區間退化（high == low）的日子需排除。
- base rate 與門檻皆在 Phase 1 探索後回填，避免事前 data snooping。
- 後續可衍生：把「10:30 高位」當進場訊號、13:45 收盤出場的當沖回測（Phase 2）。
