2026-05-21

## Parameters

- 出場：13:45 收盤平倉（最單純版本）

## Parameter Sensitivity
- 對 **pos 門檻高度敏感**：0.75 打平、0.90 才出現穩健淨正報酬 → 但「挑 0.90 最好」本身有掃描選擇偏誤（selection effect），小樣本不宜過度解讀。
- 對 **成本敏感**：gross PF 1.10 → net PF 0.99，每筆平均移動（gross ~+0.014%，約 2.8 點 @20000）僅略高於 3 點成本，成本是成敗關鍵。
- 對 **regime 敏感**：空頭年（2022）顯著虧損，多單型態不具全天候性。

## 對照基準
每天無條件做多 10:30→13:45（net）：N=1289，勝率 49.8%，總 −39.5%，PF 0.84。
→ 訊號相對「無腦做多」確實大幅改善（過濾掉早盤弱勢的虧損日），這部分 edge 是真的。

## 追加分析 1：界線時間 10:00 vs 10:30（explore_cutoff.py）
把判斷/進場界線從 10:30 提早到 10:00。

| | 界線 10:00 | 界線 10:30 |
|---|---|---|
| Phase1 pos≥0.90 大長紅率 / lift | 25.9% / 2.76x | **31.8% / 3.39x** |
| Phase1 pos≥0.90 收黑率 | 12.2% | **5.6%** |
| Phase2 pos≥0.90 IS 總% (PF) | +0.1 (1.00) | **+7.0 (1.37)** |
| Phase2 pos≥0.90 OOS 總% (PF) | +8.3 (2.58) | +6.1 (2.60) |

→ **10:30 較優**：lift 更高、收黑率更低。提早到 10:00「強勢尚未站穩」，假訊號變多（收黑率翻倍）。10:00 雖 OOS 漂亮，但 IS 幾乎打平（pos≥0.75 IS −15.2% / OOS +7.0%），IS/OOS 嚴重背離為 robustness 警訊。確認 10:30 是較佳界線。

## 追加分析 2：進場時機優化 — 等回檔再進（backtest_bbentry.py）
合格日（pos≥0.75 @10:30）改成：10:30 後先出現 1分K `%B<0`（跌破 BB(20,2) 下軌），arm 後第一根「收盤>5MA」才進，13:45 出。

- 訊號幾乎不挑日：合格日 **99.1%（431/435）** 都會觸發，中位進場 11:04 → 實際只是「延後進場」，非過濾器。
- 同一批訊號日的乾淨對照（只差進場時機）：

| | 期望值/筆 | 勝率 | 總% | PF |
|---|---|---|---|---|
| 10:30 直接進 | −0.003% | 52.9% | −1.4% | 0.98 |
| 等 %B<0 + 站上5MA 進 | **−0.025%** | 51.3% | **−10.7%** | 0.82 |

- IS/OOS 都同向（新進場一律輸）：OOS 新進場 +0.5% (PF 1.04) vs 10:30 直接進 +4.1% (PF 1.29)。

→ **等回檔再進反而更差**。順勢守高位日的正確姿勢是「已在場上」；跌破下軌在強勢日常是動能轉弱/做頭徵兆，再站上 5MA 只是反彈而非乾淨續攻。買回檔對反轉/震盪有用，對順勢是反作用力。

## Verdict
[x] **Confirmed**（限定範圍：Phase 1 的「機率」宣稱；使用者 2026-05-21 指示歸 confirmed）
[ ] Rejected
[ ] Inconclusive

**理由與範圍界定（重要）：**
1. **假設陳述本身成立**：proposal 的 hypothesis 是「早盤守高位 → 大長紅機率顯著高於 base rate」，invalidation 為 lift≤base / N<100 / 尾端>30%。實測 lift 2.3–3.4x、N=412、尾端僅 2.9% → **三個無效條件全未觸發，現象確認為真且穩健**。
2. **但這是「現象 confirmed」，不是「可獲利策略 confirmed」**：作為多單策略（pos≥0.75 + 13:45 出場）扣 3 點成本後幾乎打平（PF 0.99）；穩健淨正只在 pos≥0.90 小樣本（IS 147 / OOS 51）。
3. 進場時機調整（等回檔）與界線提前（10:00）都未能改善，反而更差 → 簡單版本（10:30 直接進）已是此框架下最佳。
4. **故：不晉升 strategies/live/**。要可交易需先解出場優化 / regime 濾網（見衍生假設）。

## Derived Hypotheses
- **H09x（出場優化）**：13:45 固定出場可能浪費了續漲。Phase 1 顯示觸發後中位 ret 0.53%、收黑僅 12%——改用 trailing stop / 早盤區間高點突破加碼 / 動態目標，可能把 gross edge 放大到能蓋過成本。最有機會把本假設救成 Confirmed 的方向。
- **H09x（regime 濾網）**：2022 空頭年是唯一大虧。加上多頭/中性 regime 濾網（如價在某均線之上才做）可能去掉空頭年的拖累，提升 PF 與心理可承受度。
- **H09x（反向偏空日）**：pos≤0.3（早盤弱勢守低位，N=362）大長紅率僅 1.7%、中位 ret −0.51%——對稱地做空 10:30→13:45 可能是更乾淨的 edge，值得獨立驗證。
