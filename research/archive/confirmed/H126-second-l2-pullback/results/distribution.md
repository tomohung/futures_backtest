# Distribution Research Results: 同向第二次 L2 拉回續攻

## Date
2026-06-24

## Conditions Tested
重用 `services/l2_pullback.detect_day`（causal，無前視）逐日掃 2021-01-29 ~ 2026-06-24 全部 L2 拉回續攻
進場，依「同方向序數」分組，零策略量測進場(收盤價)後到當日 13:45 的 forward excursion：
- 碰 L3/L4/L5 比率（以各進場 phase 的 anchor ± COEF×EMA20 為門檻，與系統關卡/目標定義一致）
- MFE / MAE（× EMA20 標準化）
- 三組對照拆 selection vs 序數：A=單次日 1st、B=多次日 1st、C=2nd+
- **時間配對對照**（控制進場時間）+ **同時段三方對照**（同時控制時間與 day-type）
- 附帶欄位（僅描述）：VWAP flip、EOD DCI

腳本：`explore.py`　明細：`results/entries.csv`（N=2052）　圖：`results/ordinal_excursion.png`

## Sample
- 總進場 N=2052，涵蓋 1180 個交易日（有 ≥1 筆 L2 拉回的日）
- 同向序數分佈：
  - short 971（1次818 / 2次131 / 3次17 / 4+次5），具≥2次同向空的日=131
  - long 1081（1次916 / 2次148 / 3次15 / 4+次2），具≥2次同向多的日=148
- **2nd+ 總 N=318**（short 153 / long 165）；其中 **進場 ≤12:00 的可交易核心 ≈168**（早24+中61+晚83）

## Key Findings

### 1. 聚合對照「會騙人」——序數與進場時間在多次日近乎共線
- 聚合：C(2nd+) reach L3/L4/L5 = 42/20/11%，**全面差於** B(多次日1st) 62/33/19%。
- 但 C 進場中位 **11:53**、B 中位 09:24。多次日「第1次必早、第2次必晚」近乎共線，
  聚合差異主要來自 **2nd+ 集中晚盤、跑道短**，不是序數本身差。
  （吻合記憶 `feedback_excursion_needs_forward_tautology_guard`：沒做時間虛無對照會誤判 reject。）

### 2. 時間配對後，序數效應翻正——2nd+ 在深目標 L4/L5 勝出（= 假設論點）
時間桶對齊系統關卡時間閘（09:30/10:30/11:30）。2nd+ vs 同時段 1st 的 reach L3 / **L4** / **L5**：

| 時段 | 2nd+ | 同時段 1st | N(2nd+) |
|---|---|---|---|
| <09:30 | —（N=2）| 70 / 40 / 21% | 2（結構上幾乎不存在）|
| **09:30–10:30** | 71 / **46** / **31**% | 62 / 28 / 14% | 52 |
| **10:30–11:30** | 60 / **35** / **18**% | 50 / 15 / 4% | 68 |
| ≥11:30 | 29 / 8 / 3% | 34 / 8 / 2% | 196 |

→ 09:30–11:30：2nd+ 的 **L4 reach ≈ 1.6–2.3×、L5 ≈ 2.2–4.5×** 於同時段 1st。
**≥11:30 整片死掉，卻佔 2nd+ 的 62%（196/318）。**

### 3. 同時段三方對照（最乾淨的純序數，day-type+time 皆固定）
**09:30–10:30（證據最強、N 紮實）：**
- **C(2nd+) 71/46/31%（N=52）** ≫ B(多次日1st) 52/24/14%（N=109）≈ A(單次日1st) 64/29/14%（N=577）
- **C vs B = 純序數效應，強烈為正**：同趨勢日同時段，第二次的 L4≈2×、L5≈2.2× 於第一次。
- 同時揭穿：聚合看到的「B>A selection 效應」是時間假象——固定時段後 B 並不優於 A。
  **帶 edge 的是序數本身（2nd+），不是「趨勢日」身分。**
10:30–11:30：C 60/35/18（N=68）≫ A 50/14/3；B 僅 N=13（多次日第一次幾乎更早發生）。
≥11:30：C 29/8/3 ≈ A 34/8/2 → 死區。

### 4. 代價：2nd+ 吃更多 heat（MAE）
09:30–10:30 的 C 中位 MAE=0.35 L vs A 0.25 L。reach 較遠但進場後逆行也較大——
**Phase 2 必須用真實停損把 MAE/賠率淨算出來**，reach↑ ≠ EV↑（母體 H120 causal 後近 break-even）。

### 5. 附帶欄位皆為 NULL（佐證設計取捨）
- **VWAP flip**：A/B/C = 95/93/99%，近乎人人有 → **無區辨力，VWAP 確實不是重點**（符合 brainstorm 決定）。
- **EOD DCI**（hindsight）：strong regime 比率 A/B/C = 33/34/36%，幾無差異 → 日級 DCI **無法事前區分** 1st/2nd+。

## Vs. Expected
**部分符合、且方向比預期更精緻**：
- 「2nd+ 續航更遠、可瞄 L4/L5」→ **成立，但僅在時間配對/同時段對照下**，且**edge 集中在 L4/L5 深目標**（非 L3）。
- proposal 預設的「B>A selection 效應」→ **被推翻**（那是時間假象）；真正的 edge 來自**序數本身**，比預期更乾淨。
- 新增邊界條件：**進場須在 09:30–11:30**（≥11:30 無 edge 且佔 2nd+ 的 62%），且 2nd+ 的 MAE 較大需 Phase 2 淨算。

**理由**：純序數效應（同時段三方對照 C≫B）在 09:30–11:30 顯著為正，方向正中假設論點（深目標 L4/L5）。
可交易核心 **N=120（09:30–11:30）**，09:30–10:30 桶 N=52、C-vs-B 對照齊全（B N=109），證據最強。
**GATE 門檻事後校準**：以「2nd+、entry∈[09:30,11:30]」為主樣本，N 足夠進 Phase 2；3次+(N=39)偏薄需標註。

**Phase 2 必驗**：(a) 真實停損下 2nd+ ∈[09:30,11:30] 的 EV 是否轉正（vs 母體 break-even）；
(b) 目標 L4/L5 vs L3 的淨賠率；(c) 對照組「同時段 1st」量化增量；(d) 11:30 cutoff 敏感度。

## Derived Hypotheses
- **H127（候選）**：序數效應與進場時間共線——或許真正的 driver 是「**晚於某時點仍出現的 L2 拉回**
  （趨勢成熟確認）」而非「第幾次」。可測「同向 ≥2 次」vs「任一次但 entry∈[10:00,12:00] 且當日已先有
  一段 ≥L3 同向延伸」何者更強，把序數拆成「前置已有延伸」的代理。
- **H128（候選）**：2nd+ 的 MAE 偏大 → 測「2nd+ 用更寬停損（容忍 re-test 第一次極值）+ L4/L5 目標」的
  賠率，可能比沿用 l2_pullback 緊停損更適配續攻情境。
