# Backtest Results: 缺口竭盡反轉（E1）

## Date
2026-03-25

## Strategy Rules

**Entry：**
- 缺口定義：夜盤收盤（05:00）vs 日盤開盤（08:45）
- ORB：08:45~08:58（14 分鐘，對齊 EstHL）
- 開高竭盡：09:00 後跌破 ORB low → 做空
- 開低竭盡：09:00 後突破 ORB high → 做多
- 方向濾網：entry 必須在 target 的正確方向（ORB 未穿過夜收）
- 進場價 = ORB 邊界（限價單）
- 進場截止 = 10:30

**Exit：**
- Target = 夜盤收盤價（補缺口）
- Stop = 測試多種方式（見下）
- Time stop = 13:30

**成本：** 來回 2 點

## Root Cause Analysis

### 為何 84% 的統計優勢沒轉化為獲利？

1. **R:R 結構性不利**
   - 夜盤缺口均值僅 0.20%（~30-60 點），但 ORB 寬度均值 ~60 點
   - Target 距離（均值 29 點）<< Stop 距離（均值 63 點）
   - R:R ratio 中位僅 0.37，即使 84% 勝率也只是損益兩平

2. **84% 的「補缺口」多數在破 ORB 的同一根 K 棒發生**
   - Phase 1 的中位補缺口時間 = 0 分鐘（同根 bar）
   - 代表 ORB 低點和夜收價非常接近，進場後可獲利空間趨近零

3. **成本不可忽略**
   - 來回 2 點 vs 平均 target 距離 29 點 = 6.9% 的利潤被成本吃掉
   - 在 R:R 已經不利的情況下，成本成為壓垮駱駝的最後一根稻草

4. **方向濾網刪除近半樣本**
   - 47% 的「竭盡反轉」實際上 ORB 已穿過夜收，根本不是可交易的反轉
   - Phase 1 的 84% 包含這些不可交易的情況

## Key Learnings

1. **高勝率 ≠ 正期望值**。84% 的補缺口率被 R:R 不利完全抵消。
2. **分佈探索的統計結論需要考慮可交易性**。「價格觸及」和「可獲利交易」是兩件事——進場點的位置決定了實際可用的利潤空間。
3. **夜盤缺口太小**。台指期夜盤 → 日盤的真實跳空僅 ~0.2%，不足以支撐反轉策略的風險報酬。

## Derived Hypotheses

- H0XX-gap-as-filter：雖然缺口竭盡反轉不適合獨立策略，但「缺口方向 + ORB 失敗」可能是現有策略（EstHL / Reversal）的有效**濾網條件**。例如：缺口日 ORB 破反向時，偏向反轉方向的信號權重加大。
- H0XX-large-night-gap：只鎖定大夜盤缺口（>=0.3%，年約 40 筆）做竭盡反轉，target 距離夠大（>=60pt），R:R 可能翻正。但樣本量可能不足以驗證。
