# Distribution Research Results: 缺口日研究

## Date
2026-03-25

## Conditions Tested
- 標的：TX（台指期）日盤 08:45~13:44
- **缺口定義（修正）**：夜盤收盤（05:00 bar close）vs 當日日盤開盤（08:45 bar open）
- 缺口%：gap_pts / night_close × 100
- 補缺口判定：開高日 → 當日低 <= 夜盤收盤；開低日 → 當日高 >= 夜盤收盤
- 竭盡反轉判定：缺口 + 破 ORB15（15 分鐘開盤區間）反向突破

**為何用夜盤收盤？** 前一版用日盤收盤（13:44），但中間隔了一整個夜盤（15:00~05:00），日盤間的「缺口」多半是夜盤走勢造成的，不是真正的跳空。夜盤收盤 → 日盤開盤才是市場真正的不連續定價。

## Sample
- 有夜盤資料的交易日：950（2021~2026）
- 時間範圍：2021 ~ 2026-03-23
- 市場：台指期（TX）日盤

## Part 3: 竭盡反轉型態分析（核心發現）

**定義**：缺口日，日盤中打破 15 分鐘開盤區間（ORB15）的反方向
- 開高竭盡：gap > 0 → 跌破 ORB15 low
- 開低竭盡：gap < 0 → 突破 ORB15 high

### 竭盡反轉的發生頻率與補缺口率

| 情境 | 破 ORB15 比例 | 破 ORB 後補缺口率 |
|------|-------------|----------------|
| 開高（全部） | 406/489 = 83.0% | 336/406 = **82.8%** |
| 開低（全部） | 365/447 = 81.7% | 313/365 = **85.8%** |

分缺口大小（開高 + 開低合併）：

| 缺口大小 | 破 ORB 比例 | 破 ORB 後補缺口率 |
|---------|-----------|----------------|
| 全部 | 771/936 = 82.4% | 649/771 = **84.2%** |
| >= 0.1% | 494/604 = 81.8% | 381/494 = **77.1%** |
| >= 0.2% | 285/355 = 80.3% | 192/285 = **67.4%** |
| >= 0.3% | 160/192 = 83.3% | 92/160 = **57.5%** |

### 年度穩定性（竭盡反轉補缺口率）

| 年度 | 補缺口率 |
|------|---------|
| 2021 | 135/158 = **85.4%** |
| 2022 | 121/145 = **83.4%** |
| 2023 | 123/147 = **83.7%** |
| 2024 | 115/141 = **81.6%** |
| 2025 | 130/150 = **86.7%** |
| 2026 | 25/30 = **83.3%** |

**極度穩定，每年都在 81~87% 之間。**

| 年度 | 補缺口率 |

| 年度 | 補缺口率 |
|------|---------|

### 補缺口時間（破 ORB 後到補缺口的分鐘數）

| 統計量 | 分鐘 |
|--------|------|
| 均值 | 13 分鐘 |
| 中位 | 0 分鐘 |
| 25th | 0 分鐘 |
| 75th | 6 分鐘 |

累積分佈：

| 時間 | 累積% |
|------|-------|
| <= 5 分鐘 | 74.4% |
| <= 15 分鐘 | 82.4% |
| <= 30 分鐘 | 88.3% |
| <= 60 分鐘 | 93.2% |

**多數在破 ORB 的同時或極短時間內就補回缺口。** 中位數 0 分鐘 = 破 ORB 的那根 K 棒往往同時觸及夜盤收盤價。

## Part 4: 日盤缺口交叉分析（保留參考）

- 缺口 vs range%：Pearson r = 0.270 (p < 0.001)
- 缺口 vs |oc%|：Pearson r = 0.149 (p < 0.001)
- 大缺口日的 range 較大（1.26% vs 0.97%），但增幅不如缺口本身
- 反轉率（開高收低、開低收高）接近 50%，無方向性 edge

| 假設 | 預期 | 實際（夜盤缺口） | 判定 |
|------|------|----------------|------|
| 顯著缺口佔比 >= 30% | >= 30% | 20.2%（>=0.3%），37.4%（>=0.2%） | **門檻應調低** |
| 補缺口率 >= 50% | >= 50% | 整體 **75.3%** | **符合** |
| 竭盡反轉補缺口率 | — | **84.2%**，年年穩定 81~87% | **強力支持** |
| 缺口 vs range r >= 0.3 | >= 0.3 | r = 0.27 | 邊緣 |

### 核心結論

1. **用夜盤收盤當基準後，補缺口率從 30.5% 翻轉為 75.3%**——之前的 invalidation 結論是因為缺口定義不對。

2. **竭盡反轉型態是真正的 edge**：
   - 發生頻率高（82% 的缺口日會破 ORB）
   - 補缺口率極高（84.2%）
   - 年度穩定性極好（81~87%，五年零漂移）
   - 速度快（74% 在破 ORB 後 5 分鐘內補缺口）

3. **缺口越大，竭盡反轉的補缺口率越低**（>=0.3% 降到 57.5%），但仍然 > 50%。

4. **策略設計方向**：竭盡反轉 = 開盤方向的失敗信號（破 ORB 反向），此時做反轉、目標補缺口（夜盤收盤價），是一個高勝率、快速了結的策略原型。
