# Proposal: 缺口日研究

## ID
H033

## Derived From
H021（策略 E1 — 缺口竭盡反轉的前提研究）

## Trading Intuition
跳空缺口代表隔夜資訊衝擊後市場的重新定價。缺口大小、方向、補缺口率等特徵，是 E1 缺口竭盡反轉策略的設計基礎。例如「開高破低 A 轉做空」需要先知道：多少日有顯著缺口、補缺口率多高、缺口大小是否影響當日 range 和方向。

## Hypothesis
台指期缺口日存在可量化的統計特徵：
1. 顯著缺口（>= 0.3%）的出現頻率穩定（各年 >= 30%）
2. 補缺口率（當日最高/低回到前收）>= 50%（缺口竭盡反轉的基礎）
3. 缺口大小與當日 range 正相關（大缺口 = 大波動日）
4. 開高日的補缺口率 vs 開低日有差異（多空不對稱）

## Expected Distribution
- 缺口日佔比 >= 30%（顯著缺口 >= 0.3%）
- 補缺口率 >= 50%（支持反轉策略邏輯）
- 缺口大小 vs range 相關性 r >= 0.3

## Invalidation Condition
- 補缺口率 < 40%（缺口竭盡反轉的前提不成立）
- 缺口日佔比 < 20%（樣本太少，不值得建立獨立策略）
- 各年度缺口特徵不穩定

## Notes
### 分析方法
1. 定義缺口：當日開盤價 vs 前一交易日收盤價（13:44 最後一根 1 分 K close）
2. 缺口分級：微小（<0.1%）、小（0.1-0.3%）、中（0.3-0.5%）、大（>0.5%）
3. 補缺口判定：
   - 開高日：當日最低 <= 前收 → 補缺口
   - 開低日：當日最高 >= 前收 → 補缺口
4. 交叉分析：缺口大小 × 補缺口率、缺口方向 × 當日 oc%、缺口 × range%
5. 時間分析：補缺口發生的時間分佈（開盤後幾分鐘？）

### 資料需求
- `ohlcv_1m`（TX 日盤，08:45 開盤與 13:44 收盤）
- 前日收盤價（需跨日查詢）

- 其他策略的缺口日濾網（如缺口日是否應跳過 ORBLong）
