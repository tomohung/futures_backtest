# Proposal: 早盤弱勢 → 大長黑

## ID
H094

## Derived From
H093（confirmed）的 distribution 階段 — 反向對稱研究。
H093 Phase 1 發現：pos_1030 ≤ 0.3（早盤弱勢守低位，N=362）大長紅率僅 1.7%、
當日中位 ret −0.51%，看起來是比多單側更乾淨的偏空訊號，值得獨立驗證。

## Trading Intuition
盤面觀察（H093 的鏡像）：當天開盤後就一路往下殺、到 10:30 仍然守在早盤區間
低位（沒有反彈拉回），這種「早盤弱勢且壓在低點」的型態，當天收盤容易收成大長黑。
想驗證：早盤弱勢守低位，是否能預測當日收大長黑，機率是否顯著高於無條件 base rate，
且做空 10:30→13:45 扣成本後是否有正期望值。

## Hypothesis
當「10:30 的收盤價位於早盤區間（08:45~10:30 的 high/low）低位（pos_1030 ≤ 0.25）」時，
當日（日盤 08:45 開盤 → 13:45 收盤）形成「大長黑」的機率，顯著高於所有交易日的無條件 base rate。

「大長黑」需同時滿足兩個條件（跌幅 + 收低位）：
1. **跌幅**：日盤實體跌幅 `(close_1345 - open_0845) / open_0845` ≤ −門檻（門檻於 Phase 1 由分佈決定，初擬 −0.6% ~ −1.0%）
2. **收低位**：13:45 收盤位於當日全幅高低區間（08:45~13:45 的 day_high/day_low）下緣，`close_pos_day ≤ 0.15`

價格序列一律使用連續合約 `adj_close`（Panama 調整，避免換倉跳空汙染）。

## Expected Distribution
- 觸發樣本（早盤守低位）應有數百筆（對稱於 H093 的多單側 N≈360–410）。
- 觸發日的大長黑機率 vs 無條件 base rate：若觀察成立，應看到明顯 lift（對標 H093 多單側 2.3–3.4x）。
- 同時看反例：觸發後反而收紅 / 大幅反彈的比例（衡量「假破底」風險）。
- **跨側比較**：偏空側的 lift / 尾端風險，是否真的比 H093 多單側「更乾淨」。

## Invalidation Condition
以下任一成立則假設不成立或無交易價值：
1. 觸發後大長黑機率 ≤ 無條件 base rate（無 lift，10:30 低位不具預測力）。
2. 觸發樣本數過少（< 100 筆），無法得出穩健結論。
3. 觸發後「收紅或大幅反彈」的尾端風險過高（如 > 30%），代表早盤弱勢無法守住，型態不可靠。

## Notes
- 「早盤區間低位位置」定義：`pos = (close_1030 - low_morning) / (high_morning - low_morning)`，pos ∈ [0,1]，越接近 0 越低。
- **regime 警示**：H093 多單側在 2022 空頭年大虧；對稱地，本偏空側很可能在 2022「過好」、在多頭年（2023/2024）吃虧 —— Phase 1 / Phase 2 必須做逐年 walk-forward，確認 edge 不是單靠某個空頭年撐起來。
- base rate 與門檻皆在 Phase 1 探索後回填，避免事前 data snooping。
- 成本沿用 H093：做空 round-trip 約 3 點（滑價+手續費+稅），績效以損益% 計。
- H093 教訓：「機率高」≠「扣成本後賺錢」，per-trade 期望移動需明顯大於成本才有交易價值。
