# Distribution Research Results: Regime 對 L1-L4 觸及率的影響與轉換偵測

## Date
2026-06-01

## Conditions Tested
- 市場：TX 台指期日盤 08:45–13:45
- 觸及定義（錨 session open，依 proposal §Notes）：
  - 上方 Ln 觸及 = `(day_high − open) ≥ coef_n × ema20`
  - 下方 Ln 觸及 = `(open − day_low) ≥ coef_n × ema20`
  - `coef`：H097 EMA-only 階梯 L1=0.385 / L2=0.497 / L3=0.711 / L4=0.977
  - `ema20` = `day_range.shift(1).ewm(span=20)`（causal，只用到前一交易日）
- 趨勢分類器（全 causal，用 adj_close 避免換倉跳空；只用到前一日收盤）：
  - **baseline `MA±std`**：`prev_close` vs `SMA20 ± 1.0×std20`，中間帶＝盤整
  - alt1 `MA-slope`：`SMA20` 5 日斜率 / MA `> ±1.0%`
  - alt2 `%-dev band`：`prev_close/SMA20 − 1` `> ±2.0%`
- 腳本：`research/active/H098-regime-reach-rate/explore.py`

## Sample
- 有效樣本（含 causal ema20 + baseline regime）：**N=1281 日**
- 時間範圍：2020-12-31 ~ 2026-05-29
- 分桶樣本（baseline）：多頭 **487** / 盤整 **564** / 空頭 **230** — 三桶皆 ≥ 100 ✓（GATE 樣本門檻達標）

## Key Findings

### 1. 主結論：regime 鑑別力**只在空方成立**，多方幾乎為零（強烈不對稱）

各 regime 上/下方觸及率（95% Wilson CI），重點 L3/L4：

| regime | 方向 | L3 觸及率 (CI) | L4 觸及率 (CI) | 不對稱度 L3 / L4 |
|---|---|---|---|---|
| 多頭 N=487 | 上方 | 23% [20,27] | 12% [9,15] | **+1% / +1%** |
|  | 下方 | 22% [19,26] | 11% [8,14] | |
| 盤整 N=564 | 上方 | 24% [21,28] | 10% [8,12] | **+1% / −3%** |
|  | 下方 | 23% [20,27] | 12% [10,15] | |
| 空頭 N=230 | 上方 | 28% [23,34] | 14% [10,19] | **−6% / −7%** |
|  | 下方 | **34% [29,41]** | **20% [16,26]** | |

CI 分離檢定（L3/L4）：
- **空頭下方 vs 盤整下方：分離 ✓**（L3：34%[29,41] vs 23%[20,27]；L4：20%[16,26] vs 12%[10,15]）
- **多頭上方 vs 盤整上方：重疊 ✗**（L3：23%[20,27] vs 24%[21,28]）→ 多頭看起來跟盤整一樣

→ 不對稱度由空→盤整→多 **不是**對稱的「負→0→正」。實際是：**空頭顯著為負（順勢往下延伸），盤整 ≈ 0，多頭 ≈ 0**。多頭並沒有「往上延伸」的可辨識傾向。

### 2. 分類器敏感度：方向穩定（非 data snooping）

| classifier | N多/盤/空 | 多 asymL3 | 盤 asymL3 | 空 asymL3 |
|---|---|---|---|---|
| MA±std (base) | 487/564/230 | +1% | +1% | **−6%** |
| MA-slope | 378/727/171 | +5% | +0% | **−12%** |
| %-dev band | 428/644/209 | +4% | −0% | **−8%** |

三個 causal 分類器一致：**空頭 asym 顯著為負（−6%~−12%）、多頭 0~+5%、盤整 ≈ 0**。結論不依賴單一分類器。

### 3. 轉換窗口 event-study：不對稱度**領先 flip ~1 日**，但多半是機械性

flip 前後 ±7 日，L3 不對稱度平均（轉多 flip n=85、轉空 flip n=65）：

| offset | 轉多 asym | 轉空 asym |
|---|---|---|
| −1 | **+0.42** | **−0.49** |
| 0 (flip) | +0.02 | −0.09 |
| +1..+7 | ≈ 0 ~ +0.08 | ≈ −0.03 ~ −0.16 |

- flip **前一日**不對稱度爆量尖峰（轉多 +0.42 / 轉空 −0.49），flip 當日即回落。
- 但這「領先」大半是**機械性**：MA±std 分類器在「決定性收盤」隔日才翻面，而那根決定性收盤本身就是極不對稱的大方向日 → 尖峰落在 −1 是定義使然，不是乾淨的多日前兆。
- 可說「盤中不對稱度**同步 ~ 略領先**於日線分類器翻面，且非落後」，但**沒有**穩定的多日領先軌跡 → 延伸假設（不對稱度當獨立轉換偵測訊號）**證據偏弱**。

## Vs. Expected
**部分符合**：
- ✅ 「空頭 → 下方遠端觸及率高、不對稱度顯著為負，且幅度 > 多頭」：完全符合，且與 H095 §5（空方鑑別力 ~2x 多方、殺盤齊跌）獨立互證——此處用 open-anchor 觸及 + 日線價格分類器，非廣度，結論一致。
- ✅ 「盤整 → 兩側遠端皆低、不對稱度 ≈ 0」：符合。
- ❌ 「多頭 → 上方遠端觸及率 > 下方，不對稱度顯著為正」：**不成立**。多頭上方與盤整重疊，asym ≈ 0。對應 H095 §5「窄幅多頭年家數鑑別力歸零」——2021/2024/2026 多頭多為窄幅權值帶動，日盤上擺並未系統性放大。
- ⚠️ 延伸（轉換領先）：僅 ~1 日且機械性，非可獨立操作的前兆。

## Caveats（重要）
- **絕對觸及率不可與名目 90/75/50/25 直接比**：H097 係數是對「最大擺幅（running-min/max 錨）」擬的；本研究改 open-anchor（proposal 指定），open 起算的擺幅較小，故 pooled L1 僅 54%（非 90%）。本假設的主張是 **regime 間的差值（delta）**，方向在三分類器下穩健，不受此影響；但若 H095 要把結論回灌成「實際距離係數」，需用 open-anchor 重擬係數（見 Derived）。

## Derived Hypotheses
- **H099（暫）：open-anchor 階梯係數重擬** — 現行 0.385/0.497/0.711/0.977 是 max-excursion 擬的；若 H095 採 open-anchor 觸及，應對 open-anchor 擺幅重新分位迴歸出一套係數，使名目達到率對齊。
- **H100（暫）：空頭日下方距離係數放大量化** — 空頭日下方 L3 觸及 34% vs 全期 25%，可量化「空頭日下方係數該乘多少」使其回到目標達到率，作為 form A 的具體參數。
- **多頭窄幅性質**：多頭日上擺不放大，疑似權值帶動的窄幅結構（與 dci_spec §5 一致）；可另接「多頭日 + 廣度齊揚」子集看上方鑑別力是否才浮現。
