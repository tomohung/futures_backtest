# Proposal: Regime 對 L1-L4 觸及率的影響與轉換偵測

## ID
H098

## Derived From
H095（reach-ladder-exit）的前置設計：L1-L4 達到率階梯（causal prior-day EMA20）。
H095 用的是 directional pooled（2021-2026）的「全期平均」觸及率來定階梯係數，
**未拆分市場 regime**。本假設問：這些觸及率是否其實隨多/空/盤整而漂移？
亦與 H057（leading-indicator-regime）相關。

## Trading Intuition
L1-L4 階梯係數（L1=0.385 … L4=0.977 × EMA20 日盤振幅）是用全期樣本擬出來的「平均」，
但平均可能掩蓋結構：
- **多頭**日：價格傾向往上延伸 → 上方遠端（L3/L4）觸及率應該偏高、下方偏低。
- **空頭**日：鏡射，下方遠端觸及率高（且殺盤齊跌，空方可能更極端）。
- **盤整**日：兩側都在中段就回，L3/L4 觸及率皆低、上下接近對稱。

若成立，H095 用單一全期係數＝把三種結構平均掉，順勢方向被低估、逆勢方向被高估。
更進一步：**regime 轉換期間**，觸及率（特別是上下不對稱度）會不會在日線趨勢分類器
翻面之前/同時就先動，能當轉換的領先或同步訊號？

## Hypothesis
**主**：以 causal 日線價格趨勢把交易日分成 多頭 / 空頭 / 盤整 後，
上方 L1-L4 與下方 L1-L4 的觸及率在三個 regime 間有統計上可分離的差異，
且差異集中在遠端（L3/L4）與「上下不對稱度」：
- 多頭 → 上方遠端觸及率 > 下方遠端，不對稱度顯著為正；
- 空頭 → 相反，不對稱度顯著為負（且幅度可能 > 多頭，對稱於 H095 §5 的空方廣度更強）；
- 盤整 → 兩側遠端皆低、不對稱度 ≈ 0。

**延伸**：regime 轉換窗口（分類器翻面前後 ±N 日）內，上下不對稱度 / 遠端觸及率
會呈現可辨識的軌跡變化，且該變化**領先或同步**於分類器翻面（而非單純落後）。

## Expected Distribution
- L1（90% 達到率設計值）在三 regime 都偏高、差異小；鑑別力主要在 **L3/L4** 與**不對稱度**。
- 盤整日：上方 L3 與下方 L3 觸及率都明顯低於趨勢日，兩者差（不對稱度）接近 0。
- 趨勢日：順勢方向 L3/L4 觸及率明顯高、逆勢方向明顯低，不對稱度分佈離 0 很開。
- 轉換窗口：不對稱度在 flip 前數日由 0 往新方向偏移（理想），或至少與 flip 同步。

## Invalidation Condition
任一即視為（部分）不成立：
1. **主假設**：三 regime 的上/下方 L1-L4 觸及率信賴區間大幅重疊、不對稱度的 regime 間差異
   不具統計顯著（CI 跨 0 且彼此重疊），代表 regime 對觸及率無鑑別力 → H095 用單一全期係數正確。
2. **延伸假設**：轉換窗口的觸及率/不對稱度變化只**落後**於分類器翻面（lag-only），
   無法提供領先或同步資訊 → 觸及率不能用來「看出」轉換。
3. **樣本**：任一 regime 桶樣本數 < 100 日，使該桶觸及率估計不可靠（需在 GATE 處理，
   例如合併或放寬分類門檻）。

## Notes
- **Causal 要求**：regime 分類器與 EMA20 階梯都必須只用到「截至前一交易日收盤」的資訊，
  才能在當日 08:45 開盤即可使用、與 H095 的盤中可用性一致。
- **觸及定義**：上方 Ln 觸及 = 當日 high ≥ (session_open + 上方距離_n)；
  下方 Ln 觸及 = 當日 low ≤ (session_open − 下方距離_n)。距離_n = 係數_n × EMA20(日盤振幅)。
  錨點用 session open（與 H095 directional-from-open 一致）。
- **分類器候選**（Phase 1 擇一定案，全部 causal）：N 日均線斜率符號＋幅度、
  收盤 vs 均線 ± k×band（中間帶＝盤整）、ADX + DI 方向。先以「收盤 vs 均線帶」為 baseline。
- 本假設偏「結構觀測 / regime 濾網」性質，Phase 2 不一定是獨立交易策略；
  更可能是回灌到 H095：①依 regime 調階梯係數或出場模式選擇（靜態 vs Dow 寬 trail），
  ②把不對稱度當轉換偵測訊號。Phase 2 方向待 GATE 後定。
