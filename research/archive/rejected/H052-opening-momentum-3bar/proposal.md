# Proposal: 開盤 3 分鐘連續收紅動能

## ID
H052

## Derived From
H050 Phase 0 批次 1 評估（G3 候選）

## Trading Intuition
開盤前 3 根 1mK 全部收紅（Close > Open），代表買方從開盤就持續主導，追價動能強烈。在這種明確的開盤方向下做多，搭配適當出場策略，可能捕捉到日內趨勢延續。

H050 初步測試顯示 N=3 做多 PF=1.43（N=134, 2021~2026），但 N≥5 反而虧損（均值回歸），說明追價動能有時效性——前 3 分鐘是甜蜜點。

## Hypothesis
當前 3 根 1mK（08:45~08:47）全部收紅時，做多至收盤有正期望值（PF > 1.2）。加入 EstHL 出場策略（SatZone 兩段式 + trailing stop）後，績效優於持有至收盤的 naive 版本。

## Expected Distribution
- 信號頻率：~10%（134/1265 天）
- 做多勝率 > 50%
- PF > 1.2（搭配出場策略後可能更高）
- 反向（3 根收綠 → 做空）也應有正期望值

## Invalidation Condition
- 加入出場策略後 PF < 1.0
- IS/OOS 分裂嚴重（IS PF > 1.5 但 OOS PF < 1.0）
- 信號日與現有策略（EstHL/Reversal）高度重疊（> 70%），無互補價值

## Notes
- H050 初步測試是 naive 版（做多持有至收盤），需要測試有出場策略的版本
- 反向（連續收綠 → 做空）在 N=6-7 有更高 PF（1.78-1.95），但樣本太少（N=15/8），暫不獨立測試
- 此策略的 edge 可能來自「開盤追價」的行為偏差，早盤散戶跟風買入推高價格
