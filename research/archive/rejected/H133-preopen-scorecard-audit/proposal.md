# Proposal: 盤前多空計分表有效性審計 + 早盤方向 edge 重探

## ID
H133

## Derived From
Origin（原創）— 起於 `src/analysis/key_prices.py` 現行「方向加分（多空計分）」表格的有效性質疑。
設計於 brainstorming 階段完成，並先行盤點既有研究（見 Prior Art）。

## Trading Intuition
`key_prices.py` 盤前會產出一張「多空計分」表，用四個依據投票判今日日盤方向偏多/偏空：

1. 1-hr MACD 方向（hist ≥ 0 為多）
2. 30分K 20MA 方向（夜收 vs 均線扣底 → 預判轉向）
3. 週幾早盤勝率（近 ~40 交易日滾動）
4. 夜盤位置 vs 昨/前日成本（二日突破 > 昨 VWAP）

目的是盤前提高早盤勝率。但這張表從未被正式驗證，且盤點後發現 **3/4 訊號對應到既有研究**，多為負面或誤用結論。需要一把統一的尺，既審計舊表、也探索更好的替代訊號。

**貫穿性教訓**：H018（confirmed）方向 r=0.30–0.44 但**損益相關性 = 0**（方向命中 ≠ 賺錢）；記憶 elec-fin：pooled 顯著度須過逐年/子期間/regime 三關，否則方向是池化假象。

## Hypothesis
在 2021–2026 全歷史、以統一 harness（方向命中率 vs base rate + 機械交易 P&L，三時段窗口、逐年/regime 拆）評估下：

- **H133-a（審計）**：現行計分表的**合計投票**在至少一個時段窗口，顯示方向 lift > 0 且機械交易 P&L 為正，且逐年 ≥4/6 年一致；並且合計投票勝過它最好的單一成分。
- **H133-b（探索）**：存在盤前可得或開盤後確認的替代訊號，其機械交易 P&L edge 逐年 ≥4/6 年成立，優於現有任一成分。

## Expected Distribution
- 個別成分（MACD、20MA、夜盤位置）方向 lift 微弱或為負、P&L 過不了成本，逐年翻號 → 印證 prior art。
- 週幾（滾動 2 個月）近乎雜訊。
- 合計投票**可能**因多訊號在趨勢日共動而略有方向 lift，但 P&L 是否成立未知（H018 警訊）。
- 替代訊號中，夜盤 05:00 收基準版位置、OR 段量比（09:30）較可能顯示 edge（後者 H018 已 confirmed）。

## Invalidation Condition
- **H133-a 不成立**：合計投票在所有三窗口，方向 lift ≤ 0，或 P&L 不過成本，或逐年 <4/6 年一致，或不勝過最佳單一成分 → 審計結論為「砍列 / 改基準」，仍是有效產出。
- **H133-b 不成立**：所有候選替代訊號 P&L edge 逐年 <4/6 年成立 → 早盤盤前方向確認為薄，回歸既有結論（H018/H056）。

## Notes
- **評估階段不調目標/停損**（避免自由度過擬合）；窗口起點進、終點出，成本 3 點/邊（沿用 H104）。
- base rate = 該窗口實際當多比例，**非 50%**（TX 有 drift）。
- OOS 注意：記憶 oos_equals_highvol_regime —— OOS 2026-03~06 ≡ 高波 regime，逐年拆比單一 IS/OOS 切更可信。
- 嚴格 causal：盤前訊號只用 08:45 前可得資料；開盤後訊號標明可得時點。
- 現貨指數盤中分K 可能無資料，Phase 2 先查可得性，沒有則用 TX/NYF 代理並標明。
- 產出去向：Phase 1 → 決定 `key_prices.py` 計分表保留/刪除/改基準哪幾列；Phase 2 → 提出更好的列；若「盤前投票 + 開盤確認閘」組合出 edge → 開 derived 假設。
