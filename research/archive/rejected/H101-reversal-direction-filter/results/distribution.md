# Distribution Research Results: Reversal 方向濾網替換（納入夜盤）

## Date
2026-06-04

## Conditions Tested
四種方向濾網，在進場窗 **09:10**（窗首 bar）的每日方向判定：

| 變體 | 定義 | 資料 |
|------|------|------|
| base | 5m 120MA 斜率（shift1 vs shift2） | 只日盤 08:45–13:45 |
| A | 5m 240MA 斜率（=1H 20MA） | 連續日+夜盤 |
| B | 1H MACD 12/26/9，MACD 線 vs Signal 線 | 連續日+夜盤 |
| C | A 且 B 同向 | 連續日+夜盤 |

方向編碼 +1 bullish / −1 bearish / 0 undefined。所有指標 shift 避免未來函數。

## Sample
- 交易日 **N = 1312**（2020-12-31 ~ 2026-06-03）
- 市場：TX 台指期日盤

## Key Findings

### 可用方向覆蓋率（暖機後幾乎全覆蓋）
- base 99.6%、A 99.7%、B 100.0% — 暖機損耗極小。

### 新濾網 vs base 歧異率（GATE 主條件）
| 比較 | 共同有方向日 | 歧異日 | 歧異率 |
|------|------|------|------|
| base vs **A** | 1304 | 266 | **20.4%** |
| base vs **B** | 1307 | 705 | **53.9%** |

- **A 與 base 相近**（僅 20% 歧異）：同為趨勢斜率，只是拉長到 1H 級別並納入夜盤。
- **B（1H MACD）與 base 差異極大**（54%）：訊號性質完全不同，多空近乎五五波（bull% 49.5% vs base 56.9%）。

### 情境 C 覆蓋率（GATE 主條件）
- A、B 皆有方向：1308 日
- **同向（C 允許交易）：735 日（56.2%）**
- 逆向（C 過濾掉）：573 日（43.8%）
- C 同向日 vs base 方向歧異：199/734 = 27.1%

### 進場窗內方向翻轉率（穩定度）
- base 15.5%、**A 25.8%**（最不穩）、**B 12.2%**（最穩）。
- 與「納入夜盤讓開盤方向更穩定」的預期**不完全相符**：A 反而比 base 更常在窗內翻轉（240MA 斜率對短期波動更敏感）；B（1H MACD）確實最穩定。

## Vs. Expected
- 「歧異率 20–40%」：A 符合（20%）；B 遠超（54%，MACD 本質差異大）。
- 「C 會減少交易筆數」：符合，C 過濾掉 44% 交易日，Phase 2 樣本量需留意。
- 「納入夜盤讓開盤方向更穩定」：**部分不符** — 只有 B 更穩，A 反而更不穩。

## Gate Decision
GATE 條件：新濾網 vs base 歧異率 > 15% 且 C 允許交易天數 ≥ 80。

- base vs A：20.4% > 15% ✓
- base vs B：53.9% > 15% ✓
- C 允許交易：735 日 ≥ 80 ✓（方向層面；實際進場仍受 BB/BC zone 限制，**真實交易筆數會遠少於此**）

## Derived Hypotheses
- **H101-d1**：B（1H MACD）窗內翻轉率最低（12%），若 MACD 方向確實穩定，或可單獨作為「方向確認延遲進場」的濾網（等 MACD 與當日 BB 訊號同向才進）。
- **H101-d2**：A 的窗內翻轉率（26%）高於 base，暗示 240MA 斜率在開盤前一小時雜訊偏高；可測「以前一交易日收盤時的 A 方向鎖定當日方向」（完全不在盤中更新）是否更穩。
