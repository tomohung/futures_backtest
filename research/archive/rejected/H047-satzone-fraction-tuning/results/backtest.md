## Phase 1 vs Phase 2 落差原因

Phase 1 探索估計所有策略在降低 fraction 後 EV 改善，但 Phase 2 回測顯示改善很小甚至反轉。主要原因：

1. **Entry-blocking 效應（S002）：** Phase 1 假設同樣的進場信號，但實際上 `_satzone_reached` 會阻擋 SatZone 觸及後的新進場。S002 交易數從 324 降到 152（-53%）。
2. **5MA cross 出場 ≠ target 出場：** Phase 1 假設新 touched 交易出場在 target 附近，但 Phase 2 用 5MA cross 出場，實際出場點可能更高或更低。
3. **小樣本效應（S003）：** N=38-39，逐年 6-17 筆，統計波動大。

## Verdict
- [ ] Confirmed
- [x] Rejected

**理由：**
1. **嚴格一致性檢驗未通過：** 沒有任何策略在任何 fraction 下，能在 IS 期間每年都 >= baseline
2. **S002 明確反效果：** 降低 fraction 減少交易數且劣化 EV
3. **S003 樣本不足：** 無法得出可靠結論，且 OOS 方向錯誤
4. **S001 邊界情況：** f=0.95 IS 總量改善 16%，但 2022/2025 各微幅劣化（-0.7/-1.0 pts）。若放寬標準可考慮，但嚴格標準下不通過

**補充說明（S001）：** f=0.95 的 IS 改善不可忽視（PF 3.00→3.58），且逐年失敗幅度極小（<1pt）。若未來需要微調 S001，fraction=0.95 值得作為候選參數重新檢視，但目前數據不足以確認。
