## 逐筆歸因（dci − base = +1.11 來自哪裡）
| 類別 | N | 貢獻 |
|---|---|---|
| 共同進場、同向 | 47 | 兩組相同 +4.49 |
| 共同進場、翻向（兩組都進、方向相反） | **0** | — |
| base 獨有日（dci 翻向後無 setup→不進） | 21 | base 放棄 **+0.04**（打平） |
| **dci 獨有日（base 無 setup、dci 翻向後有）** | **1** | **+1.16** |

- **整個 +1.11 的優勢 = 1 筆交易（+1.16）。** 拿掉它，dci ≈ base。n=48 的「贏」押在單筆上 = 雜訊。
- **方向翻轉機制本身 0 貢獻**：沒有任何一天兩組都進場卻方向相反（dci 一翻向，反方向 setup 就不出現→不進）。
- base 在「方向被判錯」的 21 個歧異日，reversal 單**仍打平(+0.04)、沒虧**。

## 多方訊號隔離（回應「先只看多方，空方等 dci_short」）
原 `dci` 用 sign(dci_long) 套多空——但 H095 已證 dci_long 只對「上行」有效、空方需 dci_short（廣度/家數）。
為排除弱空方訊號的污染，加 `dcilong`：**只在強的 dci_long>0 override 成多方，空方一律退回 base**。

| 組 | 多方單 n | 多方總% | 多方 avg | 多方 Sharpe |
|---|---|---|---|---|
| base | 49 | 3.10 | 0.063 | 0.225 |
| dcilong | 49 | 3.10 | 0.063 | 0.225 |

- **多方單與 base 完全相同**（逐欄一致）。dcilong 唯一效果＝砍掉 10 筆「龍頭強漲但 MA 偏空」的空單（淨 +0.13），**未新增/未改變任何多單**。
- 進一步直接檢驗「dci_long 能否排序 base 的 49 筆多單」：**corr(dci_long, 損益%) = +0.069 ≈ 0**；
  「強且正」子集(n=6) avg 0.066、勝率 50%，比其餘還差。**dci_long 對 reversal 多單無排序力。**
- → **即使隔離乾淨的多方訊號，對 reversal 多單也沒有效果。** 空方污染不是主因，結論不因 dci_short 而翻盤。

## 結構性對照（為何 DCI 幫得了 EstHL、幫不了 Reversal）
| | dci_long 對該策略交易的排序力 |
|---|---|
| EstHL（順勢突破，到 L3/L4=賺） | corr(MFE)=**+0.53**、到L4 50% vs 9% |
| Reversal 多單（fade 買回檔反彈=賺） | corr(損益%)=**+0.069** ≈ 0 |
**dci_long 是「趨勢/延伸」訊號**：預測「當天往上衝多遠」。順勢策略賺的正是延伸→有效；
fade 策略賺的是「回檔後反彈」→與延伸正交→無效。兩輪實證一致。

## Vs. Invalidation Condition
**命中 proposal 的 Invalidation #3**：「dci/both 未優於 base，或改善落在樣本雜訊內」——成立（改善=1 筆）。
更關鍵地，**GATE 時的核心保留被證實**：reversal 是 **fade**，base 方向猜錯≠那筆虧錢（賺的是反彈不是收盤方向），
所以「DCI 方向更準（Phase 1 歧異日 72% vs 28%）」**結構上無法轉成 fade 的 P&L**。

這從**新角度獨立再確認 H101**：方向濾網非 reversal 的 alpha 源，base 難打敗——
連「廣度型外部訊號」也打不贏，因為問題是結構性的（fade ≠ 方向賭注），不是訊號品質不夠好。

## Verdict
**[x] Rejected**（使用者裁決 2026-06-09）。理由（三層都不支持）：
1. symmetric `dci` 表面贏 base，但歸因 = **1 筆交易**；翻向機制 0 貢獻。
2. 隔離乾淨多方訊號 `dcilong`：**多單與 base 完全相同**；dci_long 對多單 corr=+0.069 **無排序力**。
3. 結構性：reversal 是 **fade**，賺「反彈」不賺「延伸」，與 dci_long（延伸訊號）正交 → 機制上幫不上。
- 命中預登記 Invalidation #3（改善落雜訊內）。獨立再確認 H101（方向非 reversal alpha、base 難打敗）。
- **空方（dci_short）形式上仍未測**（依使用者「等定義好再回來」）；但上述**結構性理由預期空方亦然**
  （fade≠方向），且多方已證無效 → 不影響本 verdict 方向。
- 微弱防禦性殘留：少單達相近報酬（回撤略低），來自選擇性、落雜訊內，非 DCI 方向機制。

## Derived Hypotheses
- **H110-d3（結構性結論）**：對 **fade/均值回歸**族，「日方向預測」不是有效槓桿（方向錯≠虧）。
  DCI 方向訊號要發揮，應接到**順勢/突破**族（方向對=賺），而非 reversal。呼應 EstHL 那輪：
  DCI 的價值在「順勢延伸」場景，不在 fade。
- **H110-d4**：dci 用更少單達相近報酬 → 若改測 **DCI 當『趨勢日 veto』**（高信心趨勢日縮量/不 fade，
  而非翻向），是否在更大樣本上提供真實的防禦性 selectivity？（與本案「翻向」不同槓桿）
