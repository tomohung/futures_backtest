# Proposal: 時間維度出場（碰 L3 後 Dow trail 的時間閘）

## ID
H099

## Derived From
H095-reach-ladder-exit 的 backtest 階段（exit_scenarios.md v5.1）。
H095 的出場框架在「碰 L3 切 🅓Dow 寬 trail」之後**只有空間維度**（pivot-low 結構），
前半場有 09:30 / 10:45 兩道進場閘、後半場無任何時間結構。本假設補上後半場的時間軸。

## Trading Intuition
碰 L3 後切到 Dow 寬 trail（更高低點移停），在**停滯／橫盤**的日子會變成無止盡等
更高 pivot low 印出、再看有沒有跌破，一路顧到 13:45 收盤強制平倉。
痛點不是 P&L 失控（停滯盤 pivot-trail 大致收在原地），而是**機會成本 + 尾盤反轉風險 +
看著浮盈空轉的心理消耗**。

直覺：前半場「早碰 L1/L2 = 真訊號」的時間結構，後半場應該有對稱版本——
「**愈晚才碰 L3，後續延伸到 L4/L5 的機率愈低**」。若成立，晚碰 L3 就不該再用寬 Dow
博長尾，而該降檔（5MA 緊收割 / 靜態），或設一道後半場閘。

## Hypothesis
對「守初始 SL 抱到 L3」的多單，以**碰 L3 的時刻 t** 為條件：
**P(L4 | L3) 與「碰 L3 後的中位延伸幅度（×EMA20）」會隨 t 變晚而單調衰減**，
且存在一個時刻 T，使 t > T 之後的續航顯著低於 pooled 平均（P(L4|L3) ~50%、median ~1.19×）。

推論（待 Phase 2 驗證）：
- t > T → 把寬 Dow 降為 🅜5MA 緊收割 / 靜態（停止博 L4 長尾）。
- 另一條「結構停滯」規則：碰 L3 後 N 根 K 棒內未印出更高 pivot low → 同樣降檔。

## Expected Distribution
- 以 L3-reacher 多單為母體，分桶（如 ≤09:30 / 09:30–10:45 / 10:45–11:30 / 11:30–12:30 / >12:30）
  計算各桶的 N、P(L4|L3)、P(L5|L4)、碰 L3 後中位延伸幅度（×EMA20）。
- 預期：早桶 P(L4|L3) 明顯高於晚桶；晚桶中位延伸趨近 0（碰到就到頭）。
- 對照組：時間是否只是「碰 L3 點數距今高」或「DCI 強度」的代理變數
  → 需在控制 DCI band 後，時間仍保有獨立衰減才算數。

## Invalidation Condition
任一成立即視為假設不成立（時間軸無獨立出場價值）：
1. 各時間桶的 P(L4|L3) 與中位延伸**無單調趨勢**，或差異落在樣本噪音內（桶 N 過小無法區辨）。
2. 控制 DCI band 後，時間的衰減消失（時間只是 DCI 的代理，無增量資訊）。
3. 找得到衰減、但任何時間閘 T 在 Phase 2 路徑回測中**不優於**「純 Dow trail 抱到 pivot-break / 13:45」
   （以平均％、carry-from-L3-high 回吐、尾盤反轉次數、連敗長度綜合評估，含 OOS）。

## Notes
- 母體沿用 H095 `explore_l3_exit_modes.py` 的「守初始SL 抱到 L3」清單（全期 N≈119、L3-reacher）。
- 評估軸**不能只看平均點數**：時間出場的價值多在「回吐／尾盤反轉／心理」軸，
  須量「從碰 L3 後最高水位的回吐」與「尾盤反轉次數」（cf. memory: filter 評估含連敗與 drawdown）。
- 多方優先；空方結構鏡射、且 H095 空方尚無 Phase 2，暫不納入本假設第一輪。
- 與 H096（觸及時間續航）相關但角度不同：H096 看「碰關卡的時間 → 是否續航」決定進場閘；
  本假設專看「碰 L3 後 → 該不該續用寬 trail」決定出場降檔。
