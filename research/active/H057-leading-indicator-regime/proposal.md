# Proposal: Leading Indicator Regime — 領先指標長線進出

## ID
H056

## Derived From
Origin（原創）

## Trading Intuition
國發會每月底公佈前一個月的「領先指標不含趨勢指數」，雖然有一個月延遲，
但從 2018-2026 的歷史數據來看，指標的拐點與台股大盤的長期頂底有明顯對應：

- 2020/11 指標高點 107.45 → 台股隨後見頂回跌
- 2022/10 指標低點 95.63 → 台股築底回升
- 2024/7 指標高點 105.11 → 台股隨後走弱
- 2026/1 指標 105.5 後急跌至 103.63（-1.80%）→ 目前進行中

即使有一個月的發佈延遲，如果拐點後的趨勢持續數個月，
仍有足夠的可操作空間做週線/月線等級的波段交易。

## Hypothesis
當領先指標不含趨勢指數出現拐點（從上升轉為連續下滑，或從下降轉為連續上升），
搭配技術指標（如月線 MA、RSI、MACD）確認，可以在台指期上建立週線/月線等級的長線部位：

- **做多訊號**：指標從低點連續回升 N 個月 + 技術指標確認
- **做空/退出訊號**：指標從高點連續下滑 N 個月 + 技術指標確認

## Expected Distribution
- 指標拐點後，接下來 3-6 個月的 TAIEX 報酬呈現方向性偏移（上升拐點→正報酬，下降拐點→負報酬）
- 搭配技術指標過濾後，勝率與報酬比進一步改善
- 即使考慮一個月發佈延遲，仍有正期望值

## Invalidation Condition
- 領先指標拐點與 TAIEX 後續 N 個月報酬無統計顯著相關（p > 0.1）
- 考慮發佈延遲後，可操作的報酬空間不足以覆蓋交易成本
- 拐點訊號過於頻繁（假突破多），導致實際不可交易

## Data
領先指標資料為使用者手動記錄，存放於本假設目錄下 `data/leading_indicator.csv`。
資料範圍：2018/8 - 2026/2（約 90 個月）。

## Notes
- 這是長線策略（週線/月線等級），與現有的日盤當沖研究不同
- 領先指標發佈時間點：每月底公佈前一個月數據
- 使用者目前已用週線 MACD 搭配，但不排斥探索其他指標
- 需要探索的搭配指標候選：週 MACD（優先）、月 SMA、月 RSI、年線（240MA）、VIX
- Phase 1 先用台指期月收盤資料做方向性探索（資料庫已有）
- 實際操作可能用 0050 ETF，但台指期與大盤方向高度相關，分佈探索階段應足夠
- 未來若建立股票資料庫（含除權息處理），可再用 0050 做精確回測
- 台指期長線部位需考慮換倉成本（每月結算一次）
- 資料來源：領先指標為國發會景氣指標查詢系統（手動記錄），台指期為期交所
