# Proposal: Opening Range Breakout 基礎策略

## ID
H022

## Derived From
Origin

## Trading Intuition
開盤初期的高低點形成一個「共識區間」，當價格突破此區間時，代表市場對方向有了新的共識，可順勢進場。

## Hypothesis
以開盤區間（08:45 ~ range_end）的高低點定義突破方向，配合固定百分比停損、停利倍數、追蹤停損，可在台指期日盤實現正期望值的當沖策略。

## Expected Distribution
- 勝率目標 >= 55%
- 盈虧比目標 >= 1.5
- 每個交易日最多出現 1 筆進場
- 13:30 前必須平倉

## Invalidation Condition
- 1,088 組參數全掃描後，無任何組合能同時達到 55% 勝率 + 1.5 盈虧比
- Pareto 前緣顯示這是策略結構的根本取捨，不是參數問題
- **結論：裸 ORB 的 edge 不足，需要加入訊號品質過濾器**

## Notes
### 策略規則
| 規則 | 說明 |
|------|------|
| **交易時段** | 日盤：08:45 ~ 13:45 |
| **開盤區間** | 08:45 ~ `range_end` 的高低點（預設 09:00，可調 08:50~09:15） |
| **多單進場** | 收盤 > 區間高 AND 當日尚未做多 |
| **空單進場** | 收盤 < 區間低 AND 當日尚未做空 |
| **每日限制** | 每個方向最多進場一次（多空互斥，後者取代前者） |
| **停損** | 進場價 +/- 進場時收盤 x 0.5% |
| **停利** | 停損距離 x tp_multiplier（預設 2.0） |
| **追蹤停損** | 09:45 後啟動；以進場後的最高/最低收盤價追蹤；回撤 0.5% 出場 |
| **強制出場** | 13:30 |

### 參數
```python
range_end_minute: int = 60     # 區間結束時間（分鐘，從 08:00 算起）
sl_pct: float = 0.005          # 停損比例（0.5%）
tp_multiplier: float = 2.0     # 停利倍數
trail_activate_minute: int = 45 # 追蹤停損啟動（09:00 後幾分鐘）
```

### 架構決策
- 連續多日回測：整段資料一次傳入，在 `next()` 內偵測日期切換並重置每日狀態
- 手動管理出場：不使用 `buy(sl=, tp=)` 參數，統一在 `next()` 處理
