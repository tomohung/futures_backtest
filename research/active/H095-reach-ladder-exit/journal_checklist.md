# 盤中出場查核表（交易日誌用）

**基礎**：`exit_scenarios.md` v5.2（達到率階梯 × 時間閘 × DCI regime × 出場模式）
**用法**：多方看 DCI_long、空方看 DCI_short（鏡射）。每碰到一個更高關卡，重讀一次。

---

## 📐 關卡與停損速查（盤前先算好掛上）

> 每階距離 = **係數 × 前一日 EMA20**（日盤振幅，causal prior-day）。
> L 從今日 session 高/低投射（多從 session_low 起算、空從 session_high 起算）。

| 階 | 達到率 | 係數 | 角色 |
|----|--------|------|------|
| **初始 SL** | — | **0.25** | 進場即掛；**碰 L3 前完全不動**（10:45 時間停損才解鎖，見鐵律） |
| L1 | 90% | 0.385 | 地板 / 第一檢核點 |
| L2 | 75% | 0.497 | 中繼 |
| L3 | 50% | 0.711 | 主要遠端目標（第一個動停損的點） |
| L4 | 25% | 0.977 | 長尾；空方 graduated scale-out 點 |
| L5 | 12.5% | 1.225 | 延伸 |
| L6 | 6.25% | 1.492 | 延伸長尾 |
| L7 | 3% | 1.777 | 延伸長尾 |

> ⚠ 所有「37% 洗單／25% 入場費」機率都 conditioned on **初始 SL = 0.25·EMA20**；若改 SL 寬度，這些數字需重算。

## 🛑 停損鐵律（最優先，先讀這條）

> **進場 → 碰 L3：守初始 SL，完全不動。**（不移 L1、不啟動 trail）
> **── 但此鐵律僅在 10:45 之前全效 ──**
> **10:45 後仍未碰 L3**：bimodal 前提失效（續 L3 僅剩 36%，H100），
> 　改啟動「時間停損」🅓Dow trail（見末段），停損開始跟最近 pivot 上移；不分強弱一律執行。
> **碰 L3 之後**（無論幾點）：才是正常動停損的點。
> 時間閘升「目標」、**10:45 是「停損」唯一的時間解鎖點**。
>
> ⚠ 注意兩條軸獨立：**「啟動 trail」管停損下緣、「瞄 L3」管目標上緣**。
> 10:45 後啟 trail ≠ 放棄 L3——目標仍照 L2 閘走（強續瞄 L3）。
>
> 為何 10:45 前不動：早碰 L2 是雙峰（72% 衝 L3／25% 全回吐到初始SL）。那 25% round-trip 是
> 72% L3 命中率的**入場費**，砍不掉——10:45 前移 SL→L1 會洗掉 **37%** 的 L3 贏單、淨虧。
> 看著 +30 點坐回虧損會痛，但這是這套高命中策略的成本，忍住別動手。
> （10:45 後此 72% 已掉到 36%，入場費的算術不再成立，故解鎖停損。）

## 🔑 消歧總則

> **任一時刻只有「你已觸及的最高關卡」那道閘是 active。**
> 碰到更高關卡 → 用新閘重讀、**覆蓋**舊閘的暫定計畫。
> L1 閘 = 暫定預報；L2 閘 conditioned on「已站上 L2」，資訊更新 → 覆蓋 L1。
> 所以「晚 L1 暫收 L2」與「早 L2 瞄 L3」**不矛盾**，是升級。
> （注意：升級的是**目標**，停損始終是初始 SL。）

**出場模式速查**（停損一律守初始SL 到 L3；以下談的是「目標/收割」）：
- ▦ 靜態目標：掛限價在 L3 到價了結（封頂 **L3 鎖死**，平均最優）
- 🅓 Dow 寬 trail：**碰 L3 後**才啟動，更高低點當移停（**唯一能放到 L4**）

> 📦 **部位顆粒度**：以下出½/⅓/¼/⅕ 需足夠口數才分得開（出⅕ 需 ≥5 口）。
> 口數不足時退化處理：**該分批卻分不開 → 留整份續 Dow trail**（寧可全抱餘量博長尾，不要硬湊小數）；
> 唯有訊號是「靜態收 / 收乾」時才全出。

**DCI 門檻**（起始值，待校準；與 `dci_daily.py` 程式碼一致）：
| | 做多 DCI_long | 做空 DCI_short |
|---|---|---|
| 強 | ≥ +0.20 | ≤ −0.20 |
| 中 | −0.10 ~ +0.20 | −0.20 ~ +0.10 |
| 弱 | ≤ −0.10 | ≥ +0.10 |

> ⚠ 兩條不同決策軸：**regime 帶** 決定「目標積極度」（強≥+0.20 才放寬閘瞄遠）；**L3 拆分線 0.2 / 0.4** 決定「先拿幾成」。
> 　0.2 這個數字同時是 regime「強」起點與「靜態↔出½」線，**數字重合、用途不同**，別混。

## ⏰ 10:45 ── L2 閘（站上 L2 後 active，覆蓋 L1 閘｜**停損仍不動**）

> 碰 L2 早於 10:45 → 博 L3｜晚於 → 守 L2
> 碰 L2 時重讀一次 DCI。**這裡不准移停損**（移 SL→L1 會洗 37% L3 贏單）。

- [ ] 實際碰 L2 時間：______（□ 早於 10:45　□ 晚於 10:45）
- [ ] DCI 重讀：______（□ 弱　□ 中　□ 強）
- [ ] ⚠️ 提醒自己：**手不要碰停損**，目標守 L3，回吐是入場費

### 碰 L2 · **早於 10:45**
- [ ] **弱**：瞄 L2 / 快收
- [ ] **中**：瞄 L3（到 L3 再依 DCI 拆分：出½鎖L3／½切🅓Dow；模式留到碰 L3 才定）
- [ ] **強**：瞄 L3，**心裡標記要獵 L4**（Dow 等碰 L3 才切，空方更該切）

### 碰 L2 · **晚於 10:45**
- [ ] **弱**：收 L2
- [ ] **中**：**一半收 L2、一半瞄 L3**（續 L3 機率 <50% → 賠率差才在這裡先落袋一半）
- [ ] **強**：仍可瞄 L3（放寬 10:45 閘）——**但有上限 ⏰ ~11:00–11:30（H100）**

> ⏰ **放寬閘上限（H100，強帶實證 N=119）**：「強→可瞄 L3」**不是無限等**。
> 碰 L2、守初始SL，等到時間 T 還沒 L3 → 之後**仍**到 L3 的條件機率：
> 10:00 **62%** → 10:45 **36%**（斷崖）→ 11:00 30% → 11:30 **25%** → 12:00 22% → 12:20 **24%**。
> → **過 ~11:00（跌破⅓）即過放寬閘上限；過 11:30 後即便強 DCI 也以 L2 為現實目標、
> L3 降為小餘量彩券（中獎率僅 ~¼）**。12:20+ 還在純等 L3 ＝ 賭 ~¾ 會落空。
> （中帶 11–14%、弱帶 ~0%；近兩年強帶稍韌，T* 取區間 11:00–11:30。）

## ⏰ 碰 L3 時（事件，記錄時間 ______）── ★ **第一個動停損的點**

> L3 只剩二選一：**切 🅓Dow 博 L4**（trail-from-L3 連平均都贏靜態 +5.5%）vs **▦靜態鎖 L3**（零回吐）。
> **多空在 L3 的分批不對稱**（H095 L4 校準，見 results/dci_l4_scaling.md）：
>
> ⏰ **時間旁註（H099，觀察用、非硬規則）**：若 **11:30 之後才碰 L3**，長尾獎池已塌——
> 歷史上晚碰 L3 只 ~11% 再上 L4（早盤 55 ~ 60%）、碰 L3 後中位只再走 0.05 ~ 0.10×EMA20。
> 留餘量博 L4 的 EV 大減，心裡有底、可考慮收乾淨一點。（樣本稀 N=9，不升級為硬規則。）
>
> ⏰ **早碰 L3（09:30 前 / gap-and-go）= 鏡對的最強訊號**：時間閘只管 L1/L2 目標，
> **不論幾點碰 L3 都照常走下方 L3 拆分決策**（依 DCI 拆）。但早碰＝長尾最豐厚（早盤續 L4 ~55–60%），
> **偏積極**：餘量偏向多留、🅓Dow trail 放寬，別急著收乾。（與上面晚碰 11:30 的收割正好相反。）

### 多方（看 DCI_long）— L3 依強度三選一：靜態 / 出½ / 出⅓（take = 1−P(L4|L3)；兩條拆分線 **0.2 / 0.4**）
- [ ] **dci_long < 0.2**：▦靜態直接拿 L3（零回吐；P(L4|L3) 未達擲銅板、偏耗竭，別逗留）
- [ ] **dci_long 0.2 ~ 0.4**：**碰 L3 出 1/2、留 1/2 切 🅓Dow trail**（P(L4|L3) ~48% 擲銅板，**唯一實測帶**）
- [ ] **dci_long ≥ 0.4**：**碰 L3 出 1/3、留 2/3 切 🅓Dow trail**（P(L4|L3) 67% 續攻佔優；0.4 以上不再細分）
- [ ] 餘量帶到 L4 後**再砍一半**（基本 take，見「碰 L4」段）；多方不做強度分級

### 空方（看 DCI_short）
- [ ] **弱/中空（DCI_short > −0.2）**：▦靜態直接拿 L3
- [ ] **強空（DCI_short ≤ −0.2）**：**碰 L3 不拆，全口切 🅓Dow 寬 trail**（空方 L4 達成率隨強度單調飆升，L3 拆等於丟肉）→ 分批延到 **碰 L4** 才做（見下）

## ⏰ 碰 L4 時（事件，記錄時間 ______）

> L4 = 25% 達到率的罕見長尾。**空方 graduated scale-out（依強度分三檔，+EV 抱肥尾）；多方砍餘量一半（基本 take，EV 中性、降變異）。**
> 空方比例 = 1−P(碰L4後續L5)，依 dci_short 強度分三檔（H095：碰 L4 後中位續到 1.5×+ EMA20，肥尾）。
> 多方不分強度——強度推不動那 ~50%、且尾巴瘦（碰L4後中位僅 ~1.2×≈剛到 L5、P(L6|L4) 僅 ~20%）。

### 空方（看 DCI_short）— 碰 L4 分批
- [ ] **≤−0.2 ~ −0.3**：出 **1/3**、留 2/3 續 🅓Dow trail（續 L5 ~65%）
- [ ] **≤−0.4 ~ −0.5**：出 **1/4**、留 3/4 trail（續 L5 ~75%）
- [ ] **≤−0.6**：出 **1/5**、留 4/5 trail（續 L5 ~81%；**別全抱**，~19% 在 L4 止步）
- [ ] 餘量續 Dow 博 L6/L7，跌破結構低點才出

### 多方（看 DCI_long）— 碰 L4：餘量再砍一半（基本 take，不做強度分級）
- [ ] **≥0.4 路徑**（手上 2/3）：碰 L4 **再出 1/3、留 1/3** 切 🅓Dow trail
- [ ] **0.2~0.4 路徑**（手上 1/2）：碰 L4 **再出 1/4、留 1/4** 切 🅓Dow trail
- [ ] 依框架自身 take = 1−P(L5|L4)（≈47~57%）；P(L5|L4) 擲銅板 + **尾巴瘦**（中位 ~1.2×、P(L6|L4) ~20%）→ **trim 是降變異、EV 中性**（不像空方 +EV）
- [ ] 餘量純 Dow trail 博瘦尾，跌破更高低點即出

## ⏰ 碰 L5 時（罕見深長尾，純餘量收割）

> 此時手上只剩 L3/L4 trail 後的小餘量。**不再博方向，目的是把長尾收乾淨。**
> 出場訊號**由鬆到緊、逐步收緊**，分批出（口數夠才分；口數不足直接用最緊那道一次出）：

- [ ] **① 目標層（最鬆）**：到 L5 價（1.225·EMA20）或 **15 分鐘預估振幅目標價** → 先峰一批
- [ ] **② 反向 K（收緊）**：連續同向 K 後**第一根反向 K** 收盤即出一批（例：紅紅紅→黑，黑 K 出）
- [ ] **③ 5MA 站回（最緊，最後一道）**：1分K 收盤**反向站回/跌破 5MA** → 餘量全清
- [ ] 口數不足以分批 → 直接用 **③** 最緊那道一次出

## ⏰ 時間停損（10:45 起，停損唯一的時間解鎖）

> 停損下緣與目標上緣是**兩條獨立軸**：這段只動「停損」，目標仍照 L2 閘。
> 「最近 pivot」＝ **1分K 最近一個 swing 高/低點（左右各約 5 根確認；多看 swing low、空看 swing high）**。

### 10:45 後仍卡在 L1→L2 或 L2→L3（未碰 L3）
- [ ] 找最近 pivot，啟動 🅓Dow trail（停損開始上移）——**不分強弱一律執行**
- [ ] **目標不變**：強續瞄 L3（上限 11:00–11:30，見 L2 閘 H100 旁註）／中半收／弱收 L2
- [ ] 跌破該 pivot → 出（trail 觸發）

### 11:30 後
- [ ] 抓 DCI 同向噴出段，**1分K 5MA 反向站回即出**

### 13:30 — 無條件全平（保險閘）
- [ ] 無論在哪一階、任何 DCI，**13:30 一律全部出清**
- [ ] （實務上極少觸發；當沖不留倉過 13:45，純防極端日抱單到收盤）
