# 盤中出場查核表（交易日誌用）

**基礎**：`exit_scenarios.md` v4（達到率階梯 × 時間閘 × DCI regime × 出場模式）
**用法**：多方看 DCI_long、空方看 DCI_short（鏡射）。每碰到一個更高關卡，重讀一次。

---

## 🛑 停損鐵律（最優先，先讀這條）

> **進場 → 碰 L3：守初始 SL，完全不動。**（不移 L1、不啟動 trail）
> **碰 L3 之後**才是第一個動停損的點。
> 時間閘只升「目標」、**永不動「停損」**。
>
> 為何：早碰 L2 是雙峰（72% 衝 L3／25% 全回吐到初始SL）。那 25% round-trip 是
> 72% L3 命中率的**入場費**，砍不掉——碰 L2 移 SL→L1 會洗掉 **37%** 的 L3 贏單、淨虧。
> 看著 +30 點坐回虧損會痛，但這是這套高命中策略的成本，忍住別動手。

## 🔑 消歧總則

> **任一時刻只有「你已觸及的最高關卡」那道閘是 active。**
> 碰到更高關卡 → 用新閘重讀、**覆蓋**舊閘的暫定計畫。
> L1 閘 = 暫定預報；L2 閘 conditioned on「已站上 L2」，資訊更新 → 覆蓋 L1。
> 所以「晚 L1 暫收 L2」與「早 L2 瞄 L3」**不矛盾**，是升級。
> （注意：升級的是**目標**，停損始終是初始 SL。）

**出場模式速查**（停損一律守初始SL 到 L3；以下談的是「目標/收割」）：
- ▦ 靜態目標：掛限價在 L3 到價了結（封頂 **L3 鎖死**，平均最優）
- 🅓 Dow 寬 trail：**碰 L3 後**才啟動，更高低點當移停（**唯一能放到 L4**）

**DCI 門檻**（起始值，待校準；與 `dci_daily.py` 程式碼一致）：
| | 做多 DCI_long | 做空 DCI_short |
|---|---|---|
| 強 | ≥ +0.20 | ≤ −0.20 |
| 中 | −0.10 ~ +0.20 | −0.20 ~ +0.10 |
| 弱 | ≤ −0.10 | ≥ +0.10 |

> ⚠ regime 帶（強≥+0.20）≠ L3 拆分界線（**0.4**）：前者決定目標積極度、後者決定先拿幾成，兩個不同決策軸。

## ⏰ 10:45 ── L2 閘（站上 L2 後 active，覆蓋 L1 閘｜**停損仍不動**）

> 碰 L2 早於 10:45 → 博 L3｜晚於 → 守 L2
> 碰 L2 時重讀一次 DCI。**這裡不准移停損**（移 SL→L1 會洗 37% L3 贏單）。

- [ ] 實際碰 L2 時間：______（□ 早於 10:45　□ 晚於 10:45）
- [ ] DCI 重讀：______（□ 弱　□ 中　□ 強）
- [ ] ⚠️ 提醒自己：**手不要碰停損**，目標守 L3，回吐是入場費

### 碰 L2 · **早於 10:45**
- [ ] **弱**：瞄 L2 / 快收
- [ ] **中**：瞄 L3（到 L3 再依 DCI 拆分：出½鎖L3／½切🅓Dow；模式留到碰 L3 才定）
- [ ] **強**：瞄 L3，**心裡標記要獵 L4**（Dow 等碰 L3 才切，空方更該切）

### 碰 L2 · **晚於 10:45**
- [ ] **弱**：收 L2
- [ ] **中**：**一半收 L2、一半瞄 L3**（續 L3 機率 <50% → 賠率差才在這裡先落袋一半）
- [ ] **強**：仍可瞄 L3（放寬 10:45 閘）——**但有上限 ⏰ ~11:00–11:30（H100）**

> ⏰ **放寬閘上限（H100，強帶實證 N=119）**：「強→可瞄 L3」**不是無限等**。
> 碰 L2、守初始SL，等到時間 T 還沒 L3 → 之後**仍**到 L3 的條件機率：
> 10:00 **62%** → 10:45 **36%**（斷崖）→ 11:00 30% → 11:30 **25%** → 12:00 22% → 12:20 **24%**。
> → **過 ~11:00（跌破⅓）即過放寬閘上限；過 11:30 後即便強 DCI 也以 L2 為現實目標、
> L3 降為小餘量彩券（中獎率僅 ~¼）**。12:20+ 還在純等 L3 ＝ 賭 ~¾ 會落空。
> （中帶 11–14%、弱帶 ~0%；近兩年強帶稍韌，T* 取區間 11:00–11:30。）

## ⏰ 碰 L3 時（事件，記錄時間 ______）── ★ **第一個動停損的點**

> L3 只剩二選一：**切 🅓Dow 博 L4**（trail-from-L3 連平均都贏靜態 +5.5%）vs **▦靜態鎖 L3**（零回吐）。
> **多空在 L3 的分批不對稱**（H095 L4 校準，見 results/dci_l4_scaling.md）：
>
> ⏰ **時間旁註（H099，觀察用、非硬規則）**：若 **11:30 之後才碰 L3**，長尾獎池已塌——
> 歷史上晚碰 L3 只 ~11% 再上 L4（早盤 55 ~ 60%）、碰 L3 後中位只再走 0.05 ~ 0.10×EMA20。
> 留餘量博 L4 的 EV 大減，心裡有底、可考慮收乾淨一點。（樣本稀 N=9，不升級為硬規則。）

### 多方（看 DCI_long）— L3 拆分二檔（take = 1−P(L4|L3)；拆分界線 **0.4**，與 regime 帶界線 0.2 是不同用途）
- [ ] **dci_long ≤ −0.1（弱/負）**：▦靜態直接拿 L3（零回吐；偏耗竭，別逗留）
- [ ] **dci_long −0.1 ~ 0.4**：**碰 L3 出 1/2、留 1/2 切 🅓Dow trail**（P(L4|L3) ~48% 擲銅板）
- [ ] **dci_long ≥ 0.4**：**碰 L3 出 1/3、留 2/3 切 🅓Dow trail**（P(L4|L3) 67% 續攻佔優；0.4 以上不再細分）
- [ ] 三檔 **L4 都不再分批**（純 Dow trail，P(L5|L4) ~45~53% 擲銅板）

### 空方（看 DCI_short）
- [ ] **弱空**：▦靜態直接拿 L3
- [ ] **中/強空**：**碰 L3 不拆，全口切 🅓Dow 寬 trail**（空方 L4 達成率隨強度單調飆升，L3 拆等於丟肉）→ 分批延到 **碰 L4** 才做（見下）

> ⚠ 強廣度日「該不該改拿靜態」的 regime 條件待重跑（§6.3）；在那之前以上述 Dow 為預設。

## ⏰ 碰 L4 時（事件，記錄時間 ______）

> L4 = 25% 達到率的罕見長尾。**空方在此做 graduated scale-out**（多方已在 L3 拆完、L4 純 trail）。
> 比例 = 1−P(碰L4後續L5)，依 dci_short 強度分三檔（H095：碰 L4 後中位仍續到 1.5×+ EMA20）。

### 空方（看 DCI_short）— 碰 L4 分批
- [ ] **≤−0.2 ~ −0.3**：出 **1/3**、留 2/3 續 🅓Dow trail（續 L5 ~65%）
