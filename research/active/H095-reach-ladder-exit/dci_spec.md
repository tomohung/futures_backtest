# DCI — 方向共識指標 (Directional Conviction Index) 規格（可攜版）

> 自包含規格，**不綁定任何專案**。用三個盤中即時市場廣度序列合成一個
> −1 ~ +1 的分數，衡量「市場往單一方向移動的一致性 + 力道（偏重權值/資金龍頭）」，
> 作為「趨勢日 vs 盤整/反轉日」的偵測器。
> 來源：台指期關卡出場研究（H095）；驗證資料 TWSE + TX 2021–2026（收盤值）。

---

## 1. 三個輸入（皆即時；盤中以「現價 − 昨收」判漲跌；各自範圍 −1 ~ +1）

### W — 上市前 20 大「權重」股 淨方向（權重加權）
```
W = Σ sign(Δ_i) · weight_i / Σ weight_i        (i ∈ 指數權值前 20 大)
```
- `Δ_i = 現價 − 昨收`；`sign = +1 漲 / −1 跌 / 0 平`
- `weight_i` = 指數權重；無權重資料時用市值（股數×價）；再無則用成交金額代理
- 意義：權值龍頭的加權方向（指數驅動力）

### H — 熱門前 20 大（成交金額）淨方向（成交值加權）
```
H = Σ sign(Δ_i) · value_i / Σ value_i          (i = 當日成交金額前 20 大)
```
- `value_i` = 當日累計成交金額
- 意義：「資金所在」的方向（當日最熱 20 檔）

### B — 漲跌家數淨值（net advance）
```
B = (上漲家數 − 下跌家數) / 上市總家數
```
- 意義：市場廣度（equal-weight 計數）

---

## 2. 合成公式

**通用版**
```
DCI = 0.40·W + 0.35·H + 0.25·B
```
`DCI > 0` 偏多、`DCI < 0` 偏空、`|DCI|` 越大方向共識越強。

**方向細分版（建議——多空不對稱，見 §5）**
```
做多用  DCI_long  = 0.40·W + 0.35·H + 0.25·B     # 權值股權重高，防窄幅多頭時家數失真
做空用  DCI_short = 0.30·W + 0.30·H + 0.40·B     # 家數權重高，殺盤齊跌時家數最準
```

---

## 3. Regime 分帶（起始值，**務必用盤中資料校準**，見 §6）

**做多（看 DCI_long）**
| 帶 | 條件 | 行動傾向 |
|---|---|---|
| 強 | DCI ≥ +0.30（≥ +0.50 高信心）| 抱 / 靜態 / 寬 trail，可追更遠目標 |
| 中 | −0.10 < DCI < +0.30 | 預設 trail |
| 弱 | DCI ≤ −0.10 | 防守 / 快收 / 不追多 |

**做空（看 DCI_short；門檻不對稱、空方訊號更強）**
| 帶 | 條件 | 行動傾向 |
|---|---|---|
| 強空 | DCI ≤ −0.20（≤ −0.35 高信心）| 抱空 / 寬 trail，可追更遠目標 |
| 中 | −0.20 < DCI < +0.10 | 預設 trail |
| 弱空 | DCI ≥ +0.10 | 防守 / 快收 / 不追空 |

## 4. Pseudocode
```python
def dci(top20w, top20v, adv):
    """
    top20w : list[(sign, weight)]  權值前20大；sign ∈ {+1,-1,0}
    top20v : list[(sign, value)]   成交金額前20大
    adv    : (up_count, down_count, listed_count)
    """
    W = sum(s * w for s, w in top20w) / sum(w for _, w in top20w)
    H = sum(s * v for s, v in top20v) / sum(v for _, v in top20v)
    B = (adv[0] - adv[1]) / adv[2]
    dci_long  = 0.40 * W + 0.35 * H + 0.25 * B
    dci_short = 0.30 * W + 0.30 * H + 0.40 * B
    return {"W": W, "H": H, "B": B, "DCI_long": dci_long, "DCI_short": dci_short}
```

## 5. 多空不對稱（核心結論，有資料支持）

驗證對象：指標 vs 台指期當日上行/下行擺動是否達 L3/L4（EMA20 達到率階梯）。

| 指標 | 上行 L3 相關 | 下行 L3 相關 |
|---|---|---|
| net_adv (B) | +0.16 | **−0.45** |
| 成交值加權 | +0.22 | **−0.49** |
| 前20大加權 | +0.22 | **−0.44** |

- **空方鑑別力是多方的 ~2 倍**：殺盤齊跌（廣度齊步），廣度對「跌」的預測遠強於「漲」。
- **多方**：漲勢可以很窄（權值帶頭），equal-weight 家數會失真，**2024/2026 窄幅多頭年家數鑑別力幾乎歸零甚至反向** → 多方才把 W/H 權重拉高。
- **空方**：家數 B 幾乎與加權版同好（殺盤廣）→ 空方可給 B 更高權重、門檻可較不極端。
- P(到 L3) 分位分離：**下行**最空分位 82% vs 最多 23%（+59~62%）；上行高分位 66% vs 低 43%（僅 +23~28%）。

## 6. 校準方法（上線前必做）

權重（0.40/0.35/0.25…）與所有門檻是**起始值**。用你的**盤中**三序列校準：
1. 取某決策時點的快照（如 09:30，或各關卡觸及當下）。
2. 對「當日是否達 L3 / L4」做迴歸或分位分析（多、空**分開**）。
3. 由「達標機率明顯跳升」的 DCI 值定門檻；由各分量的邊際鑑別力定權重。
4. **逐年檢查穩定性**（尤其多方在窄幅多頭年），門檻建議用滾動/expanding 分位而非固定值。

---

## 7. 註記
- 公式用 `sign(Δ)`（只看方向，這是已驗證版本）。含力道版可改 `Δ%`（報酬）加權：
  `Σ Δ%_i · w_i / Σ w_i`，更接近「加權指數報酬強度」，但需另行驗證。
- 驗證數據為**收盤值**；實際**盤中**即時值相關性會略低 → 門檻務必用盤中資料重訂。
- 「前20大權重股」若無權重/市值資料，用「成交金額前20大」當代理；兩者高度重疊但不等價
  （成交值排序會納入當日熱門中小型股，未必是指數權值股）。
