# Proposal: 多頭修正底部訊號 Survey（TW 版 Fear & Greed 拆解）

## ID
H084

## Derived From
Origin（CNN Fear & Greed Index 啟發；概念上鄰接 H057 leading-indicator-regime、H079 breadth-limitup-thermometer、H080 top20-concentration-regime，但目標時間框架與評估方式不同）

## Trading Intuition

CNN Fear & Greed 指數用 7 個組件衡量市場情緒，極端恐懼常常對應美股的中短期底部。台股是否能拆解出對應指標，並用來解決下面這個具體問題：

> 假設 2027–2030 是 AI 浪潮驅動的長多頭，純等「真正大底」可能等不到；但又不想在偏高位置一次把資金打進去。最好的方式是在多頭趨勢仍成立時，**於修正期分批佈局**。

過去類似情境的「必抓清單」：

- **2024-08**：套息平倉，TAIEX 約 -25%，數週反彈
- **2025-04**：關稅衝擊，TAIEX 約 -20%，數週反彈
- **2026-03**（如果出現）：類似規模的修正

這些事件都有一個共同特徵：景氣燈號沒翻空（多頭結構未破），但短期情緒/技術指標處於極值。問題在於：

1. 不同**深度**的底部可能由不同**頻率**的訊號驅動（月頻景氣燈號 vs 日頻 VIX/融資/廣度）
2. 沒有單一指標能涵蓋所有底部類型
3. 真正的「找到底部」事件樣本極少（系統熊 1-2 次、大型修正 3-5 次），純統計驗證不可行；研究必須以 case study + 條件對應為主

## Hypothesis

H084 是一個 **survey 型假設**，不直接做回測。核心命題：

> 台股市場存在 **可拆解的多指標組合**，能識別歷史相對低點，作為分批佈局的觸發訊號。整個系統採兩層架構：**慢頻 regime 切換層**（區分多頭 vs 結構熊兩種 mode）+ **快頻加碼訊號層**（在任一 mode 下觸發 tranche 投入，但 mode 不同時調整觸發門檻與 tranche 大小）。

**重要設計修正（v2，2026-05-10）**：保險絲不該是 binary stop。即使在結構熊（Tier A macro）期間，於相對低點分批進場仍有顯著正報酬（驗證：2008-2014 內各 sub-event 進場 4-6 年後皆 +27%~+127%）。所以 regime 層作用是 **modulate 而非 block**：

| Regime | 條件 | 進場行為 |
|---|---|---|
| **Mode 1（多頭修正）** | 250MA above + 景氣燈號正常 | 標準 tranche；指標達一般極值即觸發 |
| **Mode 2（結構熊內部）** | 250MA below 或 景氣連續藍燈 | 較小 tranche（如 50%）；更嚴格的觸發門檻（如百分位 ≥95 而非 ≥85）；以避開 2008-10-27 那種「假底」 |

具體可驗證的子命題：

1. 至少有 **3 個指標**在歷史 Tier B / C 底部當天呈現可重現的極值（百分位 ≥85 或 ≤15）
2. 這些指標之間至少有 **2 個彼此非冗餘**（互相關 |r| < 0.6）
3. 慢頻層（250MA + 景氣對策信號）能正確區分 Tier A regime（2008-2014、2022-2024）vs Tier B/C regime（2020-03、2024-2025、2015-08 等）— 用於 Mode 切換
4. 同一指標在 Mode 1 vs Mode 2 下的「極值型態」應有差異（這支持「不同 mode 用不同觸發門檻」的設計）

## Expected Distribution

Phase 0 Survey 預期觀察到：

### 底部分層樣本（2010–2025）
| Tier | 跌幅 | 反彈確認 | 預期樣本 |
|---|---|---|---|
| A 系統熊 | ≥30% | ≥30% | 1–2 |
| B 大型修正 | 20–30% | ≥15% | 3–5 |
| C 標準修正 | 10–20% | ≥10% | 6–10 |
| D 淺回檔 | 5–10% | ≥5% | 30–50（不主要研究）|

### 指標 vs Tier 的初步對應（待 Survey 驗證）
| 指標 | 頻率 | 主要適用 Tier |
|---|---|---|
| 景氣對策信號（綜合分數 / 燈號 / 連續月數） | 月（延遲 ~25 天） | A only |
| TAIEX 距 250MA（趨勢狀態） | 日 | A / B |
| 融資餘額減幅（vs 近期高點） | 日 | A / B |
| 台指 VIX 百分位 | 日 | B / C |
| Put/Call Ratio（成交量比、5日平均） | 日 | B / C |
| 廣度（漲跌家數比、累積值） | 日 | B / C / D |
| 52 週新低家數（TWSE+TPEX） | 日 | B / C / D |
| TAIEX 距 125MA z-score | 日 | A / B |

### 預期分佈型態
- 在 Tier B/C 底部 ±5 個交易日內，至少 3 個指標的歷史百分位會落在尾端
- 不同 Tier 的指標極值「組合特徵」應該不同（Tier C 偏快指標、Tier B 偏中速、Tier A 偏慢指標）
- Tier A 事件中，景氣燈號會連續藍燈 ≥3 個月；Tier B/C 事件中不會

## Invalidation Condition

Phase 0 Survey 結束時，若以下任一條件成立則 H084 標記為 **inconclusive** 或 **rejected**：

1. **指標可靠性不足**：少於 3 個指標在 Tier B/C 底部呈現可重現極值
2. **指標冗餘嚴重**：可靠的指標兩兩相關 |r| ≥ 0.6，本質上等於單一因子
3. **regime 切換層失效**：250MA + 景氣信號 雙條件無法可靠區分 Tier A regime vs Tier B/C regime（例如 Tier B 修正期間也會大量誤觸發 Mode 2，使 Mode 切換失去意義）
4. **資料缺口無解**：融資餘額或景氣信號歷史資料無法取得到 2010 年起

若 Survey 通過 GATE，則 H084 標記為 **confirmed**，並衍生出後續假設：
- 若 3+ 個獨立可靠指標 → 衍生「TW F&G 合成版」假設（forward-return 驗證）
- 若僅 1–2 個可靠指標 → 衍生「個別指標 forward-return 驗證」假設

## Evaluation Metric（後續假設用）

雖然 H084 本身不做回測，但為了讓衍生假設有共同的評估標準，先在這裡記錄：

- **標的**：0050 ETF（含息調整收盤）作為主要代理；AI 主動 ETF 後續再對應
- **評估窗口**：訊號觸發日後 +60D / +120D / +250D 總報酬
- **Baseline**：同期間 monthly DCA（每月最後一交易日固定金額）的平均成本與總報酬
- **成功標準**：訊號觸發日買入 vs DCA baseline，在多數歷史事件中總報酬更優、且報酬分佈右偏

## Out of Scope（YAGNI）

明確不做：

- ❌ 個股選股（標的固定 0050）
- ❌ Tier D 淺回檔研究（太頻繁，偏交易訊號而非佈局）
- ❌ 完整資金曲線回測（後續假設的事）
- ❌ 部位大小最佳化（先固定一個 tranche）
- ❌ Tier A regime 內部更細的 sub-regime 分類（Mode 1/2 的二分法已足夠）
- ❌ 殖利率倒掛、垃圾債利差等美式指標（台灣對應市場流動性不足）

## Notes

- **樣本數的硬限制**：Tier B/C 合計約 10–15 個事件。這是 case study 而非統計顯著性研究，結論偏向「指標組合在歷史事件中的型態識別」，不是「下一次必定觸發」
- **Phase 結構特殊性**：傳統 Phase 1 = 分佈探索 + Phase 2 = 回測；H084 因為性質特殊，重新定義為：
  - **Phase 0 Survey**（本假設核心）：資料齊備 + Tier 標定 + 指標軌跡 + 相關性
  - **Phase 1+**（衍生假設）：合成 / 單因子 forward-return 驗證
- **新增 ETL 工作量**：融資餘額（半天）、景氣對策信號（幾小時）— 這些 ETL 做完後，未來所有衍生假設都能用
