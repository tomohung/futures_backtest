# Proposal: L2 趨勢確立後拉回續攻（pullback breakout continuation）

## ID
H120

## Derived From
Origin（原創）。觀察來源：chart-ui 的 L3 波段匯出表（`swing_legs.py`，ZigZag 反轉門檻=L2、留淨幅≥L3）人工標註後發現——大量 ≥L3 波段在「第一段確立趨勢 → 拉回 → 突破續攻」處有明確切入點，且突破多集中在 9:30 前。

## Trading Intuition
當日開盤後，價格先做出一段達 **L2 距離（0.497×EMA20振幅）** 的方向段，確立趨勢方向；隨後出現一個**小於 L2 的拉回**（回 ≥L2 即翻向、趨勢作廢）；拉回結束後價格沿原方向重新推進、突破前波極值。這個「**L2→L3 的延伸段**」相對好吃，且有機會延伸到 L4/L5 的大行情。

關鍵自洽：chart-ui 匯出表上每一根 L3 波段，本質上就是「此 pattern 成功的案例」；表上缺的是失敗案例（突破/重新推進後沒到 L3 就反轉），那才是決定這招能不能用的關鍵。

## Hypothesis
在「≥L2 段確立趨勢 + 出現拉回（<L2）」的 setup 下，於拉回末端進場（trigger 待比較），順勢續攻**達到 L3 的條件機率，顯著高於該方向全日碰 L3 的無條件 base rate（50%）**；且進場後的 R:R（以結構停損計）為正期望，9:30 前觸發的子集 edge 最強。

**Setup / Trigger / 停損 拆解：**
- **Setup（母體）**：用 L2 門檻 ZigZag 偵測 pivot。開盤後第一個 ≥L2 方向段確立方向並記下前波極值；隨後出現反向拉回（必然 <L2）。
- **Trigger（並排比較，不預設）**：
  - (A) 拉回後價格站回 1 分 K 5MA
  - (B) 突破前波極值 + buffer
  - (C) 5MA 站回 + 一根確認（站回那根收創高/順勢 K）
- **停損（結構，以 EMA20 比例表示）**：
  - (主) 拉回低/高點 ± buffer（higher-low / lower-high 結構失效）
  - (備) 趨勢起點 pivot（完整失效才出）
- **目標**：以 ladder（自當日錨點算）衡量續攻到 L3 / L4 / L5。
- **分層**：進場時間 9:30 前 / 9:30–11:30 / 11:30 後。

ladder 定義（`daystats.py` LVL_QUANTILES，單位=EMA20振幅）：
L1=0.385（碰 90%）、L2=0.497（75%）、L3=0.711（50%）、L4=0.977（25%）、L5=1.225（12.5%）。

## Expected Distribution
- 「≥L2 確立 + 拉回」的 setup 每日約 1–3 個，全樣本（2026 起 / 可回溯範圍）數百筆量級。
- 條件續攻 L3 勝率明顯 > 50% 無條件 base rate（若不顯著高於 50%，pattern 無 edge）。
- 進場後 MAE 分佈（從真實 trigger 點算，非從 pivot 起點）集中在小區間，可框出結構停損的合理分位。
- 9:30 前觸發子集的續攻率 / R:R 優於晚盤桶。
- Trigger 比較：(A) 進場價最好但假訊號最多、(B) 確認度高但 R:R 被停損拉寬侵蝕、(C) 居中。

## Invalidation Condition
任一成立即視為（該層面）不成立：
1. **樣本不足**：合格 setup < 150 筆（無法分層）。
2. **無條件優勢**：條件續攻 L3 機率未顯著高於 50% 無條件 base rate（差距 < 5pp 或落在抽樣噪音內）。
3. **假突破吞噬**：在能保住多數贏家的結構停損下，三種 trigger 的 R:R 期望皆 ≤ 0。
4. **時間 edge 不成立**：9:30 前子集相對全時段無可辨識優勢，且全時段本身也無 edge。

> Tautology guard：續攻機率必須對比**正確的無條件 base rate**（同方向、同時間桶碰 L3 的全樣本機率），不可只看贏家目錄歸納。失敗案例（突破後未達 L3）必須納入母體。

## Notes
- 偵測尺度經討論定為 **L2（非 L1）**：L1 太細、雜訊多；L2 與 chart-ui 匯出表同尺度，且自動把「拉回」框在 <L2。
- 表上 MAE 全 0 是因為它從 swing 起點量，對實際進場無意義 → explore 必須從 trigger 點重算 MAE。
- 與既有記憶呼應：早盤（11:30 前）捕獲約 70% 全日 ladder reach；ladder reach 有多空×regime 不對稱，分層時留意 regime confound（OOS 2026-03~06 ≡ 高波 regime）。
