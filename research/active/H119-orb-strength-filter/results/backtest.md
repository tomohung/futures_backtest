# Backtest Results: 早盤期貨延伸強度當 ORB 突破濾網

## Date
2026-06-11（修正版：突破當下強度 + L3-before 排除）

## Parameters
- ORB 多單（h119_lib）：OR 窗 08:45→09:30；突破=09:30–10:00 首次 high>OR_high → 進場=OR_high
- **修正**：強度讀突破當下 CDF 延伸；突破前已達 L3 → 排除（不追延伸過行情）
- SL=entry×(1−0.5%)；TP=entry+SL距離×1.5；13:30 強平（沿用 orb.py 核心）
- 濾網：突破時 CDF 延伸 ≥ θ（主 θ=0.16）；績效用損益%，另列成本敏感度
- 樣本：突破日 N=511（排除 L3-before 後），2021–2026

## Results

| Metric | 無濾網 | 有濾網 θ≥0.16 | 低強度 <0.16 |
|---|---|---|---|
| N | 511 | 255 | 256 |
| 勝率 | 51% | **56%** | 46% |
| 均損益% | +0.033 | **+0.084** | −0.017 |
| Sharpe | +0.07 | **+0.17** | −0.04 |
| maxDD% | 6.4 | **3.6** | 6.9 |
| 最大連敗 | 8 | **6** | 7 |

→ 濾網把 EV 翻 2.5×、Sharpe 翻 2.4×、maxDD 減半；**最大連敗 6 < 無濾網 8**（修正後改善）；
**低強度 EV 轉負**（−0.017，該濾掉）。θ 穩健（0.10/0.16/0.20 均 Sharpe +0.15~0.17）。

### IS / OOS（θ≥0.16）
| | IS (2021–24) | OOS (2025–26) |
|---|---|---|
| 有濾網 勝率 | 55% | **60%** |
| 有濾網 均% / Sharpe | +0.060 / +0.13 | **+0.164 / +0.32** |
| 無濾網 均% / Sharpe | +0.016 / +0.04 | +0.095 / +0.19 |

→ **有濾網 IS/OOS 皆正且 OOS 更強**；對無濾網的增量在 IS、OOS 都在（IS Sharpe 0.13 vs 0.04）。
